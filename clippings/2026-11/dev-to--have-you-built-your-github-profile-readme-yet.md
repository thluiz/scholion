GitHub recently released a feature that allows users to create a profile-level README to display prominently on their GitHub profile.

[![ ](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2F6f9ncm5fw8q6qgyq1lcs.PNG)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2F6f9ncm5fw8q6qgyq1lcs.PNG)

To use this feature you just need to create a new repository that has the same name as your GitHub account. Mine is located at [https://github.com/mayankchaudhary26/mayankchaudhary26](https://github.com/mayankchaudhary26/mayankchaudhary26)

This repository needs to be public and initialized with a README:

[![Alt Text](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fi%2Fbtxj9vmln0rc4du1t28e.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fi%2Fbtxj9vmln0rc4du1t28e.png)

Then you have to click on edit and just type everything you want to show-up . Like here, I have written my short bio-type intro and along with that you can upload images , gifs and badges to your other social media accounts. Make your commit, push, and you’re good to go 🚀

[![Alt Text](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fi%2Ftubcpb8hqhydxvz1qh38.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fi%2Ftubcpb8hqhydxvz1qh38.png)

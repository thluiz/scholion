A Microsoft atualizou sua ferramenta PWABuilder (criador de Progressive Web Apps), que, agora, suporta o recurso Bubblewrap, permitindo criar web apps sem a necessidade de ter o Android Studio instalado.

No ano passado, a Google lançou a plataforma Trusted Web Activities (TWA), que permitiu converter aplicativos web em aplicativos nativos para o Android. Por meio da TWA, os apps são executados em janelas do Chrome, de uma forma que, nada mais, além da interface do aplicativo, seja exibido.

O novo recurso também foi responsável por adicionar o suporte para uma variedade de novas funções, provenientes do Chrome, como as notificações push, acesso offline, entre outras. Ainda assim, o TWA exigia que os apps fossem compilados como aplicativos nativos, com o uso pleno do Android Studio SDK.

Agora, essa necessidade está sendo descartada, devido ao desenvolvimento de uma nova ferramenta via linha de comando, chamada Bubblewrap, feita por funcionários da Google, mas de forma independente.

PWABuilder com suporte ao Bubblewrap

A maior vantagem do Bubblewrap, é que ele só precisa do node.js instalado para criar projetos do tipo TWA, dispensando a instalação do Android Studio SDK.

Atualmente, a Microsoft atualizou o PWABuilder, introduzindo o suporte para o Bubblewrap. Além disso, o criador de Progressive Web Apps da companhia oferece a possibilidade de personalização fácil da aplicação.

Pode-se alterar a aparência das barras de status e navegação do Android, a tela inicial do app, o comportamento de retorno durante a interação, além de algumas configurações que já são feitas automaticamente, sem necessidade de interação do desenvolvedor, o que poupa (ainda mais) tempo e trabalho.

O Google sempre tem dicas importantes para quem constrói produtos e websites. Uma dessas dicas é o projeto [Web Fundamentals](https://developers.google.com/web/fundamentals/): uma página que junta uma série de boas práticas para a construção de websites e produtos para browsers modernos.

> Web Fundamentals is a comprehensive resource for multi-device web development. We’re just getting started and want your help, if you see something amiss or have a suggestion [file an issue](https://github.com/Google/WebFundamentals/issues "File an issue on GitHub") or [submit a pull request](https://github.com/Google/WebFundamentals/pulls "Submit a pull request on GitHub").

Além de [dicas de performance](https://developers.google.com/web/fundamentals/performance/), eles colocaram uma série de boas práticas sobre [princípios de design](https://developers.google.com/web/fundamentals/principles/), dicas de como tratar as [interações de inserção de dados](https://developers.google.com/web/fundamentals/input/) pelo usuário e até [monetização](https://developers.google.com/web/fundamentals/monetization/), claro.

Indispensável e serve de referência para aquelas dúvidas rápidas que temos durante o dia a dia. Vários textos, se não todos, tem versão em português (mas isso não deveria importar, não é?).

[Web Fundamentals – Best practices for modern web development](https://developers.google.com/web/fundamentals/).

## 1/1

7 tips for writing clean code: 
 
- Merge if statements 
- Early return principle 
- Magic string -> Enum 
- Magic number -> Const 
- Prefer custom exceptions 
- Use LINQ for conciseness 
- Bool expression -> Method 
 
Good developers can spot code smells with one look at the code. 
 
This is a skill you can also learn. 
All you need is lots of practice. 
 
 BONUS - 6 more tips to improve code quality: 
 
- Write unit tests 
- Optimize for readability 
- Low coupling, high cohesion 
- Rule of 3 for code duplication 
- Consistent naming conventions 
- 10-20 lines per function (not set in stone)

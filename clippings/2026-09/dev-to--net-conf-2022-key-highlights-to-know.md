## [](#net-7-highlights).NET 7 Highlights

After the intro made with the higlights, at the .NET Conf they went on to reveal some numbers about .NET 7 and the changes presented compared to previous versions.

First of all we talk about what has been the most talked about in these months about .NET 7, yes, performance.

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A6_JBUBdUveUoxMHZlw69Nw.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A6_JBUBdUveUoxMHZlw69Nw.png)

We start with the incredible figure that [**more than 1,000 performance improvements**](https://devblogs.microsoft.com/dotnet/performance_improvements_in_net_7/) have been made in .NET 7:

*   Almost **x2** times more than in **.NET 6.**
*   **x4** times more than in **.NET 5.**

And yes developers, we are in front of the fastest .NET ever seen.

Following the theme of performance in .NET 7, now it was the turn of the APIs, again surprising us all by their high numbers.

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2AFj_23ISDZPk2mhqcQiKQLA.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2AFj_23ISDZPk2mhqcQiKQLA.png)

At first they showed that the performance improvement of the .NET 7 APIs compared to version 6 is **up to 16% faster** (_reaching_ [_up to 25% extra_](https://www.techempower.com/benchmarks/#section=data-r21&hw=ph&test=json) _in requests per second in applications such as Fortunes_).

But they not only compared it to its previous version. Also the performance of **.NET 7 APIs has been compared to its rivals**; Node.js and Java Servlet.

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A5gQEsPad91tN0GIY2yZFZw.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A5gQEsPad91tN0GIY2yZFZw.png)

As you yourself have just seen, the performance of the APIs is huge (**_up to 7.02M requests per second_**) compared to its rivals:

*   **219%** faster than Java Servlet (**_2.20M requests per second_**)
*   **1070%** faster than Node.js (**_0.60M requests per second_**)

Another point discussed was the performance of the rest APIs comparing gRPC against its rivals, again, beating them by a considerable margin reaching **up to 99.8K requests per second**.

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2AmzgiqC4gyjLcMmKbjvdAHw.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2AmzgiqC4gyjLcMmKbjvdAHw.png)

Taking these data into account, we can conclude that the performance is:

*   **3.85%** faster than Rust
*   **11.63%** faster than C++
*   **37.66%** faster than Go
*   **44.85%** faster than Java (_almost half of it!_)

It is true that we have been hearing things about minimal APIs for a couple of weeks but I know that maybe some of you don’t know what I’m talking about. Microsoft has been working on super simple APIs to start working on them and with a huge scalability.

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A2b8lA_pGUkyk0Ixx9WAgtA.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A2b8lA_pGUkyk0Ixx9WAgtA.png)

As [Gaurav Seth](https://www.linkedin.com/in/gauravseth/), director of PM for .NET\_,\_ told us in [his presentation](https://youtu.be/sMOGPRbsbcs?t=1785):

> “We are focused on ensuring everyone can build amazing APIs with .NET quiclky and scale to add powerful features as they need them.”

Let’s quickly move on to another heavyweight that has also been talked about a lot these past few months, **Blazor in .NET 7.**

## [](#net-7-amp-azure-highlights).NET 7 & Azure Highlights

We go into the new features that .NET 7 brings with Azure. For this, [Mélony Qin](https://twitter.com/MelonyQ) explains that **Azure Functions already has** [**support for .NET 7**](https://youtu.be/sMOGPRbsbcs?t=16148):

> “We also made .NET Framework supported in our Functions before host a few weeks back”

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2ACZeC6bcCuaMLBMUYJx4O-w.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2ACZeC6bcCuaMLBMUYJx4O-w.png)

At this point you may be wondering what are [Azure Functions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-overview)?

To understand it well, let’s assume a scenario where you are a .NET developer (_maybe you already are😎_) and to start a project you need to set up dependencies and configurations before you start.

This introduction alone is enough for you to understand what Azure Functions does: **it provides you with a ready-to-code environment**.

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2ARFEBkEpNCmjTrywuWFfXPQ.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2ARFEBkEpNCmjTrywuWFfXPQ.png)

In [Microsoft words](https://learn.microsoft.com/en-us/azure/azure-functions/functions-overview):

> “…Instead of worrying about deploying and maintaining servers, the cloud infrastructure provides all the up-to-date resources needed to keep your applications running.”

## [](#azure-container-highlights)Azure Container Highlights

We come to another interesting topic, the **severles containers for microservices**. This time we have [Anthony Chu](https://twitter.com/nthonyChu), Product manager working on Azure Container Apps:

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A0kCQW1ZrEw52BM-8vj4yFA.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2A0kCQW1ZrEw52BM-8vj4yFA.png)

At the [beginning of the presentation](https://www.youtube.com/watch?v=sMOGPRbsbcs&t=17664s), Anthony commented that **Azure Container Apps is a new Azure service** that came out only half a year ago.

Later, Anthony claimed that Azure Container Apps:

> “…allows you to build serverless containers for microservices.”

This is very good news because many developers and development teams are increasingly using containers and development environments.

That is why this new feature of Azure will facilitate the creation of containers in a very simple way so that developers can **focus 100% on development.**

And this was later [affirmed by Anthony](https://youtu.be/sMOGPRbsbcs?t=17736):

> “…you can focus a lot more on building your app and not have to worry about managing any infrastructure.”

At the time, when I heard that I wondered, what can I really build with Azure Container Apps?

If that’s something you’re wondering right now too, you’re in luck because Anthony has provided a [direct answer](https://youtu.be/sMOGPRbsbcs?t=17802) to that question:

[![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2AGVQXUe9SFpYWtuprfdP1kg.png)](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fmiro.medium.com%2Fmax%2F700%2F1%2AGVQXUe9SFpYWtuprfdP1kg.png)

Wednesday June 4, 2025 4:37 am PDT by [Tim Hardwick](https://www.macrumors.com/author/tim-hardwick/)

Apple's Notes app is rumored to be getting limited Markdown support in iOS 26 and macOS 26, according to _[9to5Mac](https://9to5mac.com/2025/06/03/exclusive-ios-26-messages-carplay-more/)_. The feature would allow users to export text in the markdown format.

![iOS 26 Mock Rainbow Feature](https://images.macrumors.com/t/KX5s3QPN8F9_4EB6jHu3huH7j-0=/400x0/article-new/2025/05/iOS-26-Mock-Rainbow-Feature.jpg?lossy)  
Markdown is a lightweight markup language that some writers prefer to use over rich text. Rather than using HTML for bold, italics, links, and headers, Markdown uses quick character shortcuts like \*\*bold\*\* or #header. It sounds like the feature will only add support for exporting text with markdown formatting and not writing in markdown directly.

If the rumor holds up, it's likely to be unveiled at next week's Worldwide Developers Conference alongside other iOS 26 improvements, including [automatic translation and polls in Messages](https://www.macrumors.com/2025/06/03/ios-26-messages-app-rumors/), not to mention a [major visual redesign](https://www.macrumors.com/2025/03/17/apple-believes-users-love-major-ios-19-redesign/).

## Overview

Set up your account so that customer service representatives (CSRs) are prompted to use Recurring service events relevant to the service location when booking specified job types on the Call screen. This makes using Recurring services events where applicable to both job type and the service location part of the call booking process, keeping Deferred revenue in balance. This feature is similar to [marking a recurring service event as complete after a job is booked](https://help.servicetitan.com/v1/docs/mark-recurring-service-complete-in-servicetitan-mobile).

* * *

**Who uses this feature**

*   Administrators and office employees
    
*   Primarily benefits Residential Service and Replacement business types
    
*   Applies to all trades
    

**Feature configuration**

*   Account configuration is required to use this feature. Please contact [Technical Support](http://go.servicetitan.com/ask) for details.
    

## Things to know

*   You’ll need to have recurring services set up through Memberships before CSRs can use recurring service events when booking jobs. For more, see [Create and edit Recurring service types](https://help.servicetitan.com/v1/docs/create-and-edit-recurring-service-types).
    
*   If you don’t know which job types are associated with recurring services, check your recurring service records. For more, see [Edit a recurring service type](https://help.servicetitan.com/v1/docs/create-and-edit-recurring-service-types).
    
*   If you allow for dismissed recurring service events to be booked, they’ll show up on the list of recurring service events on the Call Booking screen.  
    

## Mark a job type as required for recurring service events

Recurring services are associated with at least one specific job type. Mark those existing job types as required to ensure CSRs use recurring service events where applicable:  

1.  Go to the top toolbar and click **Settings** ![](https://cdn.document360.io/961862ab-d0f2-4d91-bb62-a62ee8184eff/Images/Documentation/icon-gnav-settings-inactive.png?sv=2026-02-06&spr=https&st=2026-09-25T08%3A08%3A52Z&se=2026-09-25T08%3A21%3A52Z&sr=c&sp=r&sig=CwxYzd5Vr88YfCJrDfw8qL%2BC9Cym7cPejaqbp%2FVt8zA%3D).
    
2.  In the side panel, go to **Operations** > **Job Types**.
    
3.  Click **Edit** next to the job type you’d like to change.  
    ![A list of tasks with priorities, durations, and edit options](https://cdn.document360.io/961862ab-d0f2-4d91-bb62-a62ee8184eff/Images/Documentation/book-recurring-service-events-on-the-call-screen-image-iwdqbh7w.png?sv=2026-02-06&spr=https&st=2026-09-25T08%3A08%3A52Z&se=2026-09-25T08%3A21%3A52Z&sr=c&sp=r&sig=CwxYzd5Vr88YfCJrDfw8qL%2BC9Cym7cPejaqbp%2FVt8zA%3D)
    
4.  Select **Make selecting a Recurring Service Event required when booking jobs if Recurring Service Events exist for the location**.  
    ![Checkbox for requiring a Recurring Service Event when booking jobs is highlighted](https://cdn.document360.io/961862ab-d0f2-4d91-bb62-a62ee8184eff/Images/Documentation/book-recurring-service-events-on-the-call-screen-image-4tpkxf4w.png?sv=2026-02-06&spr=https&st=2026-09-25T08%3A08%3A52Z&se=2026-09-25T08%3A21%3A52Z&sr=c&sp=r&sig=CwxYzd5Vr88YfCJrDfw8qL%2BC9Cym7cPejaqbp%2FVt8zA%3D)
    
5.  When you're done, click **Save**.
    

## Use a recurring service event when booking a job

After you’ve enabled this feature, selecting a recurring service event becomes part of the job booking workflow for any job with recurring service events on the service location. During job booking, if you click a service location with recurring service events, you’re notified about the number of recurring service events on that service location.

1.  Click **Use Recurring Event** to select one of the recurring service events for the job you are booking.  
    ![recurring events available](https://cdn.document360.io/961862ab-d0f2-4d91-bb62-a62ee8184eff/Images/Documentation/book-recurring-service-events-on-the-call-screen-image-z9yypffp.png?sv=2026-02-06&spr=https&st=2026-09-25T08%3A08%3A52Z&se=2026-09-25T08%3A21%3A52Z&sr=c&sp=r&sig=CwxYzd5Vr88YfCJrDfw8qL%2BC9Cym7cPejaqbp%2FVt8zA%3D)
    
2.  The _Select Recurring Event_ window opens.  
    ![Table displaying recurring events with service names, due dates, and statuses](https://cdn.document360.io/961862ab-d0f2-4d91-bb62-a62ee8184eff/Images/Documentation/book-recurring-service-events-on-the-call-screen-image-zc28476x.png?sv=2026-02-06&spr=https&st=2026-09-25T08%3A08%3A52Z&se=2026-09-25T08%3A21%3A52Z&sr=c&sp=r&sig=CwxYzd5Vr88YfCJrDfw8qL%2BC9Cym7cPejaqbp%2FVt8zA%3D)
    
3.  Click **Filter ![](https://cdn.document360.io/961862ab-d0f2-4d91-bb62-a62ee8184eff/Images/Documentation/book-recurring-service-events-on-the-call-screen-image-u01h9l50.png?sv=2026-02-06&spr=https&st=2026-09-25T08%3A08%3A52Z&se=2026-09-25T08%3A21%3A52Z&sr=c&sp=r&sig=CwxYzd5Vr88YfCJrDfw8qL%2BC9Cym7cPejaqbp%2FVt8zA%3D)** and use sorting to find the recurring service events applicable to the job.
    
4.  If you're going to do the work for more than one recurring service event in a single job, select each that applies to this job.
    
5.  If you’ve made selecting a recurring service event required when booking jobs of a certain job type if recurring service events exist for the service location, you’ll need to select one to move forward with your booking workflow.
    

For more on the call booking process, see [Book a job](https://help.servicetitan.com/v1/docs/book-a-job)

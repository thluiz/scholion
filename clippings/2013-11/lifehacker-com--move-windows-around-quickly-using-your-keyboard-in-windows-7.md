Windows 7: One of the best features of Windows 7 is its keyboard support for moving and arranging application windows. Press the Win key and an arrow key to easily dock windows side-by-side, maximize them, minimize them, and move them to another monitor. P

These are the killer shortcuts for manipulating the active window:P

- Win+Left arrow: Snap to the left half of the screenP
- Win+RIght arrow: Snap to the right half of the screenP
- Win+Up arrow: Maximize the windowP
- Win+Down arrow: Minimize/Restore if it's maximizedP

If you have more than one monitor:P

- Win+Shift+Left arrow: Move window to the monitor on the leftP
- Win+Shift+Right arrow: Move window to the monitor on the rightP

I use the Win+Left arrow and Win+Right arrow all the time on Windows, for comparing documents side-by-side or just keeping the browser open for reference while writing in another window. I'd go so far as to say the Win+arrow key shortcuts are a pretty good reason to upgrade to Windows 7 if you haven't already. (Not using Windows 7? In Windows Vista and XP, you can [tile windows with the Ctrl key and right-clicking](http://lifehacker.com/229612/windows-tip-tile-two-windows-with-just-two-clicks). For Mac users, there are several [apps to get this Windows-like shortcut](http://lifehacker.com/5809879/how-to-get-windows-best-features-on-mac-os-x); I'm using free [ShiftIt](http://code.google.com/p/shiftit/).)

# Planejando compras para fazer uma mudança

Acho que uma das principais preocupações ao se fazer uma mudança são os gastos com os quais não contávamos, como os gastos com a mudança em si. Por isso, elaborei uma lista de itens extremamente necessários para usar na mudança, além de uma lista essencial de objetos que você já deve ter na nova casa, quando se mudar.

### Itens para a mudança

- estilete para abrir as caixas
- tesoura para cortar a fita e outra pessoa também usar para abrir as caixas
- caixas de papelão
- canetas hidrográficas
- etiquetas de identificação
- fitas adesivas para embalar as caixas
- jornal velho para preencher espaços nas caixas (usei muito!)
- plástico-bolha para embalar itens delicados
- fichário ou pasta com plásticos para guardar tudo o que for referente à mudança
- trena para medir os cômodos e as compras novas
- máquina fotográfica para documentar tudo o que puder
- cópias das chaves

### Itens para a casa nova

- telefone
- filtro de água
- tábuas nos vasos
- documentos
- aspirador de pó
- balde
- mop ou rodo com panos de chão
- vassoura
- detergente
- papel higiênico
- papel-toalha
- flanelas
- panos de limpeza
- pelo menos um espelho
- toalhas
- lista com telefones úteis
- caneta e bloco de notas
- lanterna e pilhas
- celular e carregador
- produtos de limpeza
- sacos de lixo
- alimentos e bebidas para um lanche rápido
- um lugar para sentar e descansar alguns minutos
- alguns copos e pratos
- lâmpadas

**Se possível, já ter no local:**

- geladeira
- varal instalado
- máquina de lavar
- fogão

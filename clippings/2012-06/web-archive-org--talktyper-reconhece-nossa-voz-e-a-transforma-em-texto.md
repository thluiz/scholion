As vez o uso da nossa voz para edição de texto é necessário, tanto para a velocidade como para solucionar problemas específicos, como falta de teclado ou problemas nos dedos. TalkTyper é um serviço que permite a edição de texto com a nossa própria voz, sendo compatível com português. Apenas temos que selecionar o idioma e, sem necessidade de cadastro, apertar o botão verde para começar a falar.

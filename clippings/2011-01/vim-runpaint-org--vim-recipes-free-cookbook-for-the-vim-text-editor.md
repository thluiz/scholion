# Vim Recipes

Vim Recipes is a free cookbook for [Vim](http://www.vim.org/),
the popular text editor. It’s available in:

- [PDF](http://vim.runpaint.org/vim-recipes.pdf)
  format (good for printing or downloading).
- [HTML](http://vim.runpaint.org/toc/) format (good for reading on-line).
- [Bziped Tarball](http://vim.runpaint.org/vim-recipes.tar.bz2) format (good for downloading on Linux/Mac).
- [Zip](http://vim.runpaint.org/vim-recipes.zip) format (good for downloading on Windows).

You can subscribe to the [Atom feed](http://vim.runpaint.org/index.atom), or follow
[*@vimrecipes*](http://twitter.com/vimrecipes) on [Twitter](http://twitter.com/), to be notified of new recipes.

Please report any problems, typos, and suggestions via the [issue tracker](http://github.com/runpaint/vim-recipes/issues) or
e-mail to [*runrun@runpaint.org*](mailto:runrun@runpaint.org).

The latest source for the book is available from [GitHub](http://github.com/runpaint/vim-recipes).

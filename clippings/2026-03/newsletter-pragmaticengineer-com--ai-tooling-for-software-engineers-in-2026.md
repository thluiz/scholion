# AI Tooling for Software Engineers in 2026

> Claude Code dominates tool usage, leaders are more positive about AI than engineers, staff+ engineers are the biggest users of AI agents, and more. Exclusive data and analysis from 900+ respondents

Which AI tools are software engineers using, and what do they really think of them? We asked The Pragmatic Engineer subscribers, and nearly a thousand of you have shared your experiences of using AI tools for work. The survey ran for weeks, between 27 January and 17 February 2026.

This article provides a high-level overview of those findings from our latest AI tooling survey.

There are plenty of interesting details, most notably, validation of just how much Anthropic and Claude Code have risen to dominate tooling usage. Claude Code is today nearly as widespread as GitHub Copilot was in our survey three years ago (in the spring of 2023) – which shows how fast the AI market moves.

In today's issue, we cover:

1. Interesting findings: Claude Code has rocketed to #1 in just eight months, AI is fully mainstream with 95% weekly usage among respondents, and more.
2. Most-used AI tools: Claude Code leads the pack, followed by chatbots and GitHub Copilot. Cursor's rising fast, and newcomers like Codex and Antigravity are gaining traction. Most engineers juggle two to four tools at once.
3. Popular models: Anthropic's Opus and Sonnet models dominate coding tasks by a wide margin, with more mentions than all others combined.
4. AI trends: mainstream adoption achieved. 95% of respondents report using AI tools at least weekly, 75% use AI for half or more of their work, and 56% report doing 70%+ of their engineering work with AI.
5. AI agent usage rising: 55% of respondents now regularly use AI agents, with staff+ engineers leading adoption on 63.5% usage in the survey results. Agent users are twice as excited about AI as non-users are.
6. Company size and tool usage: smaller places overwhelmingly favor Claude Code (75% at the tiniest businesses), while large enterprises default to GitHub Copilot. This popularity is probably down to enterprise procurement preferences – and Microsoft's enterprise marketing efforts.
7. Tools engineers love: Claude Code is the most loved tool at 46%, far ahead of Cursor on 19% and GitHub Copilot at 9%. Senior leaders are especially enthusiastic about Claude Code.
8. Demographics: Overview of who took part in the survey.

## 1. Interesting findings

Ten personal, most-interesting findings from this survey:

1. Claude Code has gone from zero to be the #1 tool in only eight months. Released in May 2025, it's already the most-used AI coding tool, overtaking GitHub Copilot and Cursor.
2. AI is now mainstream. 95% of respondents use AI tools at least weekly, or more often, and 75% use AI for at least half their software engineering work.
3. Cursor is catching up fast on GitHub Copilot. Cursor is doing more than fine, growing in mentions 35% since the previous survey nine months ago.
4. Most engineers juggle multiple AI tools. 70% use between two and four tools simultaneously, while 15% use five or more.
5. Staff+ engineers are the heaviest agent users. 63.5% use agents regularly; more than regular engineers (49.7%), engineering managers (46.1%), and directors/VPs (51.9%).
6. Codex is seeing explosive early growth. Despite not existing during the last survey, OpenAI's Codex already has 60% of Cursor's usage.
7. Using agents correlates strongly with being positive about AI. People using agents are nearly twice as likely to feel excited about AI while non-users are twice as likely to be skeptical.
8. Company size influences tool choice more than preference. Huge companies (10K+) more likely to use Copilot (56%), tiny startups mostly go with Claude Code (75%) and Cursor (42%).
9. A tight chatbot race. ChatGPT, Gemini, and Claude as standalone chatbots have nearly equal numbers of mentions.
10. Directors and senior leaders are especially into Claude Code. The survey finds this tool is twice as popular with these folks as it is at less senior levels, while Cursor gets less love as seniority increases.

## 2. Most-used AI tools

Tools mentioned, in order of popularity: Claude Code, Chatbots (ChatGPT, Claude, Gemini, and others), GitHub Copilot, Cursor, Codex, Gemini CLI, OpenCode, Antigravity, JetBrains Junie, Zed, Windsurf, Amp, Augment Code, Factory.

Notable trends:
- Claude Code has massive momentum and is already the market leader, since its May 2025 release.
- Cursor has grown circa 35% in nine months and now threatens GitHub's popularity.
- Chatbot usage remains high. Combined mentions for ChatGPT, Claude, Gemini, Perplexity, and others used outside of coding apps are still higher than for any other tool except Claude Code.
- GitHub Copilot usage stable. Nine months ago, 46% of respondents said they used GitHub Copilot. Since then, it's barely risen.
- Explosive growth for Codex. Wasn't available during the last survey, but now already has 60% of Cursor's usage.
- Up-and-coming tools: OpenCode, Gemini CLI, Antigravity. None had launched nine months ago, but today they're used by around 10% of respondents.

### Chatbot usage: ChatGPT leads – just about

ChatGPT, Gemini, and Claude have almost equal numbers of mentions.

### Tool usage: multi-tool

Most tech professionals use between two and four AI tools:
- 70% of survey participants mention using between two and four tools
- 15% use a single tool
- 15% are using 5 or more

## 3. Popular models

Anthropic's Opus and Sonnet dominate the ranking of models used for coding. Opus 4.5 and Sonnet 4.5 (latest models at the start of the survey) come up more often than all other models, combined. Around 1 in 8 respondents say they just use whatever model is the default at their company.

Other mentions include: Cursor's custom Composer/Composer-1 model and "Cursor Auto", Kimi/Kimi K2.5 (Moonshot), DeepSeek model variants (R1, V3.2, Coder), Alibaba's Qwen/Qwen3, xAI's Grok, various Mistral models.

## 4. AI trends: Mainstream adoption achieved

95% of respondents are using AI tools weekly, at a minimum; only 2.1% don't use them at all.

### How much software engineering work gets done with AI?

- Only 25% of respondents use AI for less than 40% of their work
- 56% do 70% or more of their work using AI
- 75% use AI for at least half of their software engineering work

## 5. AI agent usage rising

Eighteen months ago, AI usage was mostly for code generation and tab completion. This year, 55% say they regularly use AI agents — 507 people, a massive jump.

Most common use cases for agents: code review and code validation, automating manual/annoying tasks, bug fixing/investigating bugs, code investigation, debugging, "crafting" or "weaving" code together with the agent.

A common arrangement in the survey is the split-screen setup: a terminal with Claude Code open to drive work, and an IDE also open to review changes made by the agent.

Tools mentioned by regular AI agent users: Claude Code is the clear leader (71% usage), followed by GitHub Copilot (46%) and Cursor (39%).

Staff+ engineers are the heaviest users of agents: 63.5% use agents regularly, versus 46.1% of leads/engineering managers.

The more someone uses AI, the more they also use AI agents. Segments: heavy users (80%+ tasks or hourly use), moderate users (30-80% of tasks or daily use), light users (30% or less, weekly/monthly use).

The more positive someone is about AI, the more likely they are using agents regularly:
- Using agents seems to make people nearly twice as enthusiastic about AI (61%) as those who do not use them (36%)
- Respondents who don't use agents are twice as likely to be skeptical (22%) about AI than those using agents regularly (11%)

## 6. Company size and tool usage

The smaller a team or company is, the more likely it is to use Claude Code or Codex. Claude Code is used by 75% of the smallest companies and teams. At the smallest places, most-used tools in order: Claude Code (75%), Chatbots (55%), Cursor (42%), GitHub Copilot (35%), Codex (26%), Gemini CLI (14%), OpenCode (13%).

GitHub Copilot overtakes Claude Code at large companies — Microsoft is very good at enterprise sales, and at bundling GitHub Copilot in its suite of products.

Cursor and OpenCode usage drops at massive companies (10,000+ employees), where large companies often build their own internal coding agents: Block's Goose, Meta's internal agent, Google's Jetski (its version of Antigravity) and Cider.

Google's Gemini CLI and Antigravity usage is notably stable regardless of company size, hovering at around 10% from the smallest to largest workplaces.

The feeling that respondents can experiment at work correlates with Claude Code being available. Claude Code is new enough (9 months old) to have not yet been approved at companies with bureaucratic processes for approving new tools.

## 7. Tools engineers love

Respondents were asked which AI tools they love using the most. 57% of respondents mention either Claude Code (46%) or Claude models (11%) as the tools they are attached to. Cursor was at 19%, double GitHub on 9%.

Other notable tools with two or more mentions: Warp, Zed, Amp, Cline, RooCode, Continue.dev.

Claude Code is especially loved by Director-and-above folks — both Claude Code and Cursor become less loved as seniority goes up, but senior engineering leadership positions are obsessed with Claude Code, not Cursor.

GitHub Copilot is equally loved by engineering managers as Cursor is. Both OpenCode and GitHub Copilot are surprisingly loved by Staff+ engineers — OpenCode rivals GitHub Copilot on "loved" mentions despite being used about a quarter as much.

Segmenting by company size: Claude Code is less frequently mentioned as a "loved" tool as company size increases; GitHub Copilot sees the opposite trajectory, more loved within larger companies where it's likely harder to experiment with alternatives.

## 8. Demographics

906 responses total. Engineers comprise 55% of respondents, engineering leadership another 34%. The median respondent has 11-15 years of experience. Company size is a fairly even split. Region-wise, most respondents are in Europe or the US.

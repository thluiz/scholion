Um belo dia, eu resolvi copiar todoso s backups de fotos que encontrei para um único computador, organizar a coleção de fotos, desisti de usar o iPhoto e comecei a usar o Picasa, assim consigo manter a mesma interface para acessar as fotos no Mac e no Windows.  
  
Isto criou uma grande confusão de arquivos duplicados, eu procurei algo pronto na internet, mas nada que me agradace, então resolvi escever um script simples para fazer esta “limpeza”, depois ainda vou ter ue organizar tudo manualmente, mas mesmo assim, já é uma grande ajuda [anexo ausente]  
  
  
  
E para unificar toda a coleção em um único lugar, falta só utilizar como diretório principal para a coleção, um armazenamento na nuvem destes, existem vários, Skydrive, Dropbox, GoogleDrive, …

  

Bom, mas fora a parte manual, de garantir que as fotos restantes estão no album que eu quero e coisas do gênero, a parte mais difícil era identificar e remover os arquivos duplicados, que por causa de algumas besteiras feiras estavam pelo menos duplicando o número de fotos no HD …

  

Para resolver isto, fiz este script, que coloquei no gist para se alguem quiser melhorar ele …

  

Espero que seja útil para alguem.

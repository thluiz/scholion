This page lists a few resources for programmers interested in learning about the Go language.

## Books

A selection of books about Go.

*   [The Go Programming Language by Alan A. A. Donovan and Brian W. Kernighan](http://www.gopl.io/)
*   [Go in Action by Brian Ketelsen, Erik St. Martin, and William Kennedy](http://manning.com/ketelsen/)
*   [Programming in Go by _Mark Summerfield_](http://www.qtrac.eu/gobook.html)
*   [Learning Go by _Miek Gieben_](http://miek.nl/downloads/2015/go.pdf) (nearing completion)
*   More books, [http://go-lang.cat-v.org/books](http://go-lang.cat-v.org/books)

## Installing Go and configuring your workspace

Start here to learn how to set up a workspace to write Go code.

*   [How to Write Go Code](http://golang.org/doc/code.html)
*   [Writing, building, installing, and testing Go code](http://www.youtube.com/watch?v=XCsL89YtqCs)
*   [Five suggestions for setting up a Go project](http://dave.cheney.net/2014/12/01/five-suggestions-for-setting-up-a-go-project)  
    

## Editors and IDEs

*   Sublime Text via the [GoSublime plugin](https://github.com/DisposaBoy/GoSublime).
*   Vim via the [go-vim plugln](https://github.com/fatih/vim-go).
*   [GoLand from Jetbrains](http://www.jetbrains.com/go/), the makers of IDEA.
*   [An incomplete list of Go tools](https://dominik.honnef.co/posts/2014/12/go-tools/).
*   and [more from the Go Community Wiki](https://github.com/golang/go/wiki/IDEsAndTextEditorPlugins).

## Online resources

Once you’ve got your environment set up, here are some excellent resources to learn Go.

*   [The Go programming language tour](http://tour.golang.org/)
*   [The Go Bootcamp Book](http://www.golangbootcamp.com/book/), everything you need to know to get started with Go, by [Matt Aimonetti](https://twitter.com/mattetti).
*   [Go by example](https://gobyexample.com/)
*   [Effective Go](http://golang.org/doc/effective_go.html)
*   [The Go language FAQ](http://golang.org/doc/go_faq.html)
*   [The Go style guide](https://github.com/golang/go/wiki/Style)
*   [Damian Gryski’s Gophervids](http://gophervids.appspot.com/) is an aggregator for recordings of Go meetups and conferences.
*   [Going Go Programming](http://www.goinggo.net/ "Going Go Programming") by [William Kennedy](https://plus.google.com/u/1/107537752159279043170/posts "William Kennedy")
*   [An incomplete list of Go tools](http://dominik.honnef.co/posts/2014/12/an_incomplete_list_of_go_tools/) by [Dominik Honnef](http://dominik.honnef.co/)
*   [Go Koans](https://github.com/cdarwin/go-koans)

## Presentations

Here is a selection of presentations about Go targeted at those wanting to learn about the language.

*   [Getting started with Go](http://www.youtube.com/watch?v=2KmHtgtEZ1s), by Andrew Gerrand.

*   [Go at Google](http://www.infoq.com/presentations/Go-Google), Rob Pike, SPLASH 2012.
*   [Organising Go code](http://talks.golang.org/2014/organizeio.slide#1) by David Crawshaw

## Community resources

Interact with the Go programming community.

*   [The Go Forum.](https://forum.golangbridge.org/)
*   #go-nuts IRC channel at Freenode. For the truly curious the channel is logged by [botbot.me](https://botbot.me/freenode/go-nuts/).
*   [Gophers’ community on Slack](https://gophers.slack.com/messages/general/)
*   [#golang](https://twitter.com/search?q=%23golang) on Twitter.

*   [Go user groups and meetups](http://code.google.com/p/go-wiki/wiki/GoUserGroups).
*   [golang-nuts mailing list](https://groups.google.com/forum/?fromgroups#!forum/golang-nuts). This is a high volume list. You may find it more rewarding to interact with the group via email, rather than the Google Groups web interface.
*   [Gopher Academy](http://gopheracademy.com/).
*   [Go questions](http://stackoverflow.com/questions/tagged/go) on Stackoverflow.
*   [Godoc.org](http://godoc.org/).
*   [The Go Programming Language Blog](http://blog.golang.org/).
*   [Go community Wiki](https://github.com/golang/go/wiki).

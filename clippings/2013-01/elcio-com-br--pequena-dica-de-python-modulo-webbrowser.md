O módulo webbrowser permite abrir uma URL no navegador do usuário. Só isso, simples assim. Por exemplo:

  

```
 import webbrowser  
 webbrowser.open("http://visie.com.br")
```

  

E o site da [Visie](http://visie.com.br) será aberto no navegador do usuário. Muito útil se você está fazendo um programa para desktop ou mesmo um script para o terminal. No caso de scripts para terminal, se o usuário estiver rodando o script sob uma interface gráfica o site será aberto no navegador padrão dele, já se estiver rodando via ssh ou num outro terminal sem interface gráfica, será usado um navegador de CLI (como o [Lynx](http://lynx.isc.org/lynx2.8.7/index.html)) se estiver disponível.

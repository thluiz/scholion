O artigo apresenta JavaScript como a linguagem padrão da web e também presente no servidor. A orientação central é aprender a linguagem antes de frameworks e estudar seus conceitos e particularidades, como escopo, closures, eventos, protótipos, performance, debug e a especificação ECMAScript.

## Fichamento

- Aprender JavaScript vem antes de depender de jQuery, MooTools ou outro framework.
- É preciso entender como a linguagem funciona por baixo dos panos, inclusive objetos, funções, herança por protótipos, escopo e eventos.
- O livro *JavaScript: The Good Parts* é indicado como leitura obrigatória para aprofundar técnica e conhecer partes problemáticas da linguagem.
- Escopo global, `this` e closures são pontos centrais para escrever código legível e organizado.
- Funções anônimas e funções autoexecutáveis ajudam a isolar trechos de código em escopos próprios.
- Eventos têm papel importante no desenvolvimento orientado a eventos e também podem ser criados como eventos personalizados.
- JavaScript usa objetos e cadeia de protótipos, sem classes, e isso permite compartilhar atributos e métodos entre objetos criados a partir de um protótipo.
- Performance deve ser observada em eventos, `setTimeout` e `setInterval`, com testes em diferentes navegadores e configurações.
- Ferramentas como Chrome Developer Tools e Firebug ajudam nos testes de performance e no debug.
- A especificação ECMAScript é o caminho para acompanhar mudanças e novas funcionalidades da linguagem.

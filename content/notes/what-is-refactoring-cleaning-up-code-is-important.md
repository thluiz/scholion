Refactoring is presented as a software change focused on structure, so the code becomes easier to understand and modify while keeping observable behavior unchanged. The page also says refactoring is a way of cleaning up code to make it easier to work with.

## Reading notes

- Refactoring changes the structure of software without changing its observable behavior.
- It makes code cleaner and easier to understand and modify.
- After refactoring, the code should be easier to work with.
- Refactoring can involve changes that produce little or no behavior change.
- Tests help measure whether refactoring changed anything unintentionally.
- The work involves adding tests when they do not exist and changing production code.

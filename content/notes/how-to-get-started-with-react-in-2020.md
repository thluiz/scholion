The article lays out a sequence for learning React that starts with the official documentation and beginner-friendly video material. It says to postpone Redux, Webpack, Babel, and similar tools until they are actually needed, then move on to building a project of your own and, if useful, paying for more polished courses or workshops.

## Reading notes

- React is presented as widely used, which makes the abundance of learning material both helpful and hard to navigate.
- The author says the list is ordered, so readers can skip ahead if they already know some topics.
- Redux, Webpack, Babel, sagas, GraphQL, and other related tools should be skipped at the start.
- The React documentation is described as the best starting point because it is structured, translated, and broken into manageable parts.
- The docs section includes the main concepts, tutorial, advanced guides, hooks, and the API reference.
- Kent C. Dodds' beginner guide is recommended as a free video course made up of 19 videos and 77 minutes.
- Michael Chan's holiday series is recommended as a step-by-step React introduction in 24 parts.
- After tutorials and videos, the next step should be building a project of your own.
- The article suggests that real learning comes from shipping features to actual users and dealing with changing code over time.
- Paid options named in the article include Egghead, Frontend Masters, TestingJavaScript, Tyler McGinnis, and Wes Bos.
- As a bonus, the article points to a workshop that reimplements a basic working version of React and ReactDOM from scratch.

A página reúne seis ferramentas de linha de comando úteis para desenvolvimento web. O foco está em depurar problemas, automatizar tarefas, inspecionar tráfego e testar desempenho sem depender de interfaces gráficas.

## Fichamento

- Curl mostra o conteúdo de uma URL na linha de comando e ajuda a depurar respostas HTTP com cabeçalhos, redirecionamentos, autenticação básica, cookies e cabeçalhos manuais.
- Ngrep permite filtrar pacotes de rede como o grep filtra arquivos, com opções úteis para tráfego web e filtros por host, IP, porta ou conteúdo.
- Netcat cria conexões de rede arbitrárias, serve como scanner de portas, pode ouvir conexões de entrada e permite combinar transferência de arquivos e acesso remoto com outros comandos.
- Sshuttle faz tunelamento seguro do tráfego por um servidor SSH, inclusive DNS, sem instalar software no servidor, e também pode ajudar a contornar restrições baseadas em IP.
- Siege é uma ferramenta de benchmark HTTP que exibe pedidos e respostas, mede carga com conexões simultâneas e pode repetir URLs de um arquivo para reproduzir tráfego real.
- Mitmproxy atua como proxy HTTP com suporte a SSL, inspeciona e reescreve tráfego HTTP e HTTPS, grava e reproduz sessões e pode ser usado para testes automatizados de fluxos web.

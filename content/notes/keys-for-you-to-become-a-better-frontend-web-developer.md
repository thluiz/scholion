The page frames frontend growth as moving beyond repeated UI templates and dummy projects. It presents itself as a checklist and says the reader should look up unfamiliar terms, then build deeper knowledge across language, version control, backend basics, bundlers, and personal tools.

## Reading notes

- Learn JavaScript as a programming language, including types, scopes and closures, hoisting, OOP, async code, array higher-order functions, browser interaction, and destructuring with spread.
- Understand async JavaScript through callbacks, promises, async-await, generator functions, and data fetching with XHR to update HTML.
- Get comfortable with Git branching, checkout, merge variants, cherry-pick, revert, reset, push, pull, and code reviews.
- Do not stay with only one framework or library; moving between two can build broader problem-solving experience.
- Learn basic backend topics such as ERDs, entities, models, relational databases, SQL, CRUD operations, foreign keys, joins, and tables.
- Study module bundlers such as Webpack and Parcel, including file trees, code splitting, optimization, and how they build assets for delivery.
- Personalize working tools like the text editor and terminal, and use them to track branches, changes, and git status more clearly.

The page gathers 11 JavaScript tools meant to simplify development work and speed up coding. It presents a mix of libraries, plugins, task runners, chat apps, and design tools for browser and Node.js use.

## Reading notes

- Countable.js is a tiny standalone function for counting text, including inputs with HTML tags stripped.
- Converse.js is an open source chat application that connects to XMPP/Jabber servers and supports one-to-one and multi-user conversations.
- Hitch is a small JavaScript prollyfill engine that adds an extension model for CSS and HTML features.
- JSHint detects errors and potential problems in JavaScript code and helps enforce team coding conventions.
- Squel.js builds SQL query strings through an object-oriented API and works in the browser and with Node.js.
- Responsive-Nav simplifies responsive menus with a lightweight footprint, touch events, CSS3 transitions, and support for screen readers and JavaScript-disabled states.
- amMap adds interactive map functionality to web pages and JavaScript applications, including location maps, route maps, and presentation use.
- Grunt is a command-line build tool for JavaScript projects with predefined tasks such as concatenation, validation, minification, and unit tests.
- Candy is an open source JavaScript chat application that uses Jabber for real-time communication and supports multiple rooms, public and private chat, and a tabbed interface.
- Roole is a JavaScript-based CSS alternative inspired by SASS, LESS, and Stylus, with built-in vendor prefixing, variables, and conditional logic.
- Radi is a visual design application for the web that uses HTML and JavaScript, includes graphics and animation tools, and supports canvas output in modern browsers.

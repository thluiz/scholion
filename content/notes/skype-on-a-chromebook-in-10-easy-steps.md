The post gives a new method for running Skype on a Chromebook after an older method stopped working. It tells the reader to check whether Chrome OS is 32-bit, 64-bit, or ARM, download the matching ARChon Runtime, then load the Skype APK through Chrome extensions. It also warns that disabling the extension or rebooting can require some steps again.

## Reading notes

- Check the Chrome OS version in Settings under About Chrome OS to see whether the device is 32-bit, 64-bit, or ARM.
- Download the matching ARChon Runtime zip file.
- Open the zip file in the File Manager, copy the extracted folder, and paste it into the needed folder.
- Download the Skype APK, choosing the smartphone or tablet version depending on preference.
- Open the Skype zip in the File Manager so it can be used in the next step.
- Go to More Tools and then Extensions from the hamburger menu.
- Enable Developer Mode.
- Use Load unpacked extension and select the extracted ARChon folder.
- Ignore the red errors that appear after loading.
- Use Load unpacked extension again and select the Skype folder inside the Skype zip.
- Click Launch or open Skype from the normal launcher once it is installed.
- If Enabled is unticked on the Skype extension, the process has to be done again.
- The first boot and login can take a long time.
- If the Chromebook is rebooted while Skype is still opened from a zip, step 10 has to be repeated.
- The author credits Vlad Filippov for the work and recommends getting the files from his GitHub page.
- The post also mentions ARChon Packager as a way to pack Android apps and install them on a Chromebook.

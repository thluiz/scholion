A good name compresses multiple meanings into one word, the way Deadspin promises ESPN with an unexpected angle, or Voldemort reads as a villain on sight. This piece walks through five tools for getting there, worked through a running example: naming a dating app for gym goers.

## Reading notes

- OneLook searches by partial word or topic and lets you combine constraints, useful for building word lists around shared letters or syllables (searching "*:exercise" then "*f*:dating" chains toward candidate names).
- RhymeZone finds homophones, near-rhymes, and phrases, sortable by syllable count or popularity, for punning on an existing word.
- Baby Name Wizard covers names for people (real ones, or fictional users in a mockup), with popularity over time and an advanced search by ethnicity, religion, or spelling.
- Fantasy Name Generators offers hundreds of name types across fictional universes, useful even just to calibrate whether a name should sound throaty, melodic, or monosyllabic.
- A long Wikipedia entry's "See Also" and "Category" sections work as a brainstorming tool once the obvious keyword search is exhausted.
- Instant Domain Search checks every extension, not just .com, following how podcasts like Reply All settled for domains like replyall.limo when the obvious one wasn't free.

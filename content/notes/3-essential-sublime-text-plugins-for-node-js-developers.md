The post recommends three Sublime Text plugins for JavaScript and Node developers: JsFormat for formatting JavaScript and JSON, JSHint for finding errors and potential problems, and JavaScriptNext for better syntax highlighting, including ES6 syntax. It also notes the basic keyboard shortcuts or menu paths for using each plugin.

## Reading notes

- JsFormat formats JavaScript and JSON, works on full files or selected text, and supports customizable settings, including per-project .jsbeautifyrc files.
- JSHint detects errors and potential problems in JavaScript code and helps enforce coding conventions; the post suggests running it on save with SublimeOnSaveBuild.
- JavaScriptNext improves JavaScript syntax highlighting for ES5 and adds highlighting for ES6 features such as modules, succinct methods, arrow functions, classes, and generators.
- The post says these three plugins have been beneficial for the author as a JavaScript and Node developer.

O texto ensina a montar um media center residencial com Raspberry Pi controlado pelo controle remoto da Smart TV. O conjunto reúne reprodução em Full HD, organização automática da biblioteca, download de filmes e séries em alta qualidade, legendas em português do Brasil e avisos no smartphone quando houver lançamentos.

## Fichamento

- O tutorial propõe um media center com Raspberry Pi que funciona de forma silenciosa, usa XBMC e pode ser controlado pelo controle remoto da TV
- O sistema apresenta filmes e séries com pôster, ficha técnica, sinopse em português e organização por nome, ano, diretor e atores
- O autor monta o setup para baixar filmes e episódios automaticamente via torrent, guardar os arquivos nas pastas certas e atualizar a biblioteca do XBMC
- O texto explica a escolha de hardware, incluindo modelo do Raspberry Pi, cartão SD, cabo HDMI, rede e fonte confiável
- O HD usado para vídeos deve ter alimentação externa; se isso não for possível, o texto sugere um hub USB energizado
- O passo a passo ensina a instalar o Raspbmc, acessar o aparelho por SSH e criar pastas para downloads incompletos, concluídos e torrents
- O Deluge é configurado para baixar arquivos colocados na pasta de torrents e para iniciar junto com o sistema
- O CouchPotato é usado para monitorar filmes, baixar automaticamente os lançamentos disponíveis e enviar o resultado para a biblioteca do XBMC
- O Sick Beard faz o mesmo com séries, baixando novos episódios, organizando os arquivos e atualizando o XBMC
- O XBMC é ajustado para português do Brasil, para o idioma correto de legendas e para a organização de filmes e séries como bibliotecas separadas
- O tutorial mostra como instalar complementos de legendas e como buscar legendas pelo próprio XBMC
- Também ensina a transferir arquivos por FTP e a fazer backup do cartão SD para poder restaurar o sistema depois
- No fim, o texto compara Raspbmc, XBian e OpenELEC, dizendo que o Raspbmc foi o mais estável para esse uso

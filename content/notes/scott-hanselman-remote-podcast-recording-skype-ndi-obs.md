Hanselman describes a remote podcast recording setup built around Skype with NDI enabled into OBS. The setup uses Sony A6000 cameras, ring lights, and Elgato 4K capture dongles.

He says AirPods work well as earbuds, but any USB podcasting mic is fine. OBS records to an MKV file with isolated audio tracks, and he uses this setup for [[azurefriday|Azure Friday]] with [[robcaron|Rob Caron]].

The article presents Mark Forster’s Commitment Inventory as a way to manage attention instead of trying to fit more into the same day. The method starts by listing all commitments, trimming the list, assigning percentages to each area, and making sure each category gets enough time to be done well.

It then translates those priorities into Todoist projects, sub-projects, checklists, and timed bursts. The system is meant to make saying no easier, keep current responsibilities visible, and reduce resistance by turning vague tasks into smaller steps.

## Reading notes

- List all commitments across work, life, and personal responsibilities, including errands and basic needs.
- Trim the list by combining overlapping categories and removing lower-priority commitments.
- Assign each category a percentage of available time so the total adds up to 100%.
- Keep only the categories that receive enough time to be done well.
- Turn categories into top-level projects and use sub-projects for related work.
- Use checklists instead of broad to-do lists so tasks feel more concrete and manageable.
- Work in timed bursts so attention stays on one category at a time.
- Reassess the commitment inventory regularly as priorities change.
- The method helped the author let go of yoga teaching and some volunteering so she could focus on her novel and other priorities.

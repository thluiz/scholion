Evernote is presented as a free note-taking tool that works across web, desktop, and mobile devices. The article focuses on practical uses that make notes easier to capture, organize, search, share, and extend with extra tools.

## Reading notes

- Access notes on PC, Mac, phones, tablets, and browsers as long as there is web access.
- Record audio notes on desktop or mobile devices, and listen back or re-record them.
- Add images by drag and drop, email, web clipping, and then search text found inside images.
- Use Evernote extras such as Skitch, Evernote Hello, and Evernote Clearly for device-specific features.
- Use the web clipper to save web information while keeping the address, tags, and notebook choice.
- Create and remove tags easily, then use them to find related notes later.
- Save searches so repeated queries stay available with one click.
- Send notes to Twitter, Facebook, or email, and tweet notes into Evernote.
- Choose among local notebooks, synchronized notebooks, and public notebooks depending on how widely notes should be shared.
- Upgrade to Premium for more storage, offline access on mobile, PDF search, collaborative editing, and fewer ads, while also using the Evernote Trunk add-ons.

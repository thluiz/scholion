## Reading notes

- Many people working from home during the coronavirus pandemic lack familiar tools and collaboration methods and may benefit from an in‑house cloud server.
- Nextcloud Hub is presented as a powerful, flexible on‑premises cloud solution that can be self‑hosted or used through a hosted provider.
- The latest Nextcloud Hub release includes Only Office, giving users an office suite similar to Google Docs or Office 365 but under their own control.
- Self‑hosting documents can address company concerns about keeping sensitive data off third‑party services like Google Docs and Office 365.
- Hosting Nextcloud on a local network can mitigate unreliable internet connections, allowing work to continue when external connectivity is lost.
- Nextcloud supports integrations via its App Store with services such as Draw.io, GitHub, OneDrive, Zimbra Drive, Google Drive, and Dropbox.
- By connecting Nextcloud to other cloud services and sharing folders, users can simplify collaboration with coworkers.
- Nextcloud Hub includes Talk, a built‑in chat, video, and audio conferencing tool that supports private, group, public, and password‑protected calls.
- Talk offers screen sharing and integrates with other Nextcloud applications for unified collaboration.
- To use Talk with external participants, the Nextcloud server needs a public‑facing IP address, which may favor choosing a hosted deployment.
- Without external access, Talk can still support communication among people inside the same household, reducing physical interruptions to work.
- Using Talk within the home can be helpful when household members are unsure about each other's health status.
- A VPN solution such as WireGuard can be configured so external users can securely access the Nextcloud server.
- The author refers readers to separate guides on installing Nextcloud 18 on Ubuntu Server and on installing Ubuntu Server 18.04 if they need setup help.
- Working from home can raise concerns about privacy and security compared to operating inside a company network.
- Users may handle more personal data at home and can use Nextcloud to separate work and home information into different directories on the same server.
- Keeping both work and personal data on a self‑hosted Nextcloud means the data stays private and away from third parties.
- After finishing a project, users can selectively share stored data from Nextcloud according to their needs.
- Nextcloud can be customized by adding only the apps required for daily work, limiting access to authorized users.

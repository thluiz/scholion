Numeric Javascript is presented as a JavaScript library for sophisticated numerical computation in the browser and elsewhere. The page highlights example areas such as linear algebra, complex numbers, splines, ODE solving, unconstrained optimization, and PDEs with sparse linear algebra.

The site also describes a Workshop for writing and sharing worksheets of JavaScript commands, with plotting support through Flot. It notes performance benchmarks, automated unit tests in several browsers, a Google Group for discussion, and a public GitHub repository.

The post gathers books and resources the author found useful for learning Elixir, arranged from introductory material to intermediate and advanced topics. It also points readers toward Erlang and OTP, plus a set of broader functional-programming books and community resources.

## Reading notes

- The list is subjective and ordered in a roughly logical sequence for someone learning Elixir.
- Programming Elixir is presented as the best published introductory book, though it assumes some prior programming experience and has useful exercises.
- Introducing Elixir is described as lighter reading and a good companion to Programming Elixir, with similar coverage and reference value.
- Elixir Cookbook is treated as a strong introductory supplement because it reframes standard topics as recipes and adds concepts and tricks not covered elsewhere.
- Études for Elixir is recommended for practice because it contains only exercises and is available free online.
- Elixir in Action is recommended after the foundations, especially for people who want to build their own projects and see deep language understanding.
- Metaprogramming Elixir is presented as a guide to one of Elixir’s strongest features, writing code that writes code.
- Programming Erlang is singled out as the main Erlang book, and Erlang and OTP in Action is recommended for mastering OTP concepts.
- Learn You Some Erlang for Great Good! is listed as another good Erlang introduction.
- SICP, Discrete Mathematics and Functional Programming, The Little Schemer, Functional Programming in Scala, The Joy of Clojure, and Joe Armstrong’s thesis are included as useful non-Elixir resources for functional programming, recursion, software design, and distributed systems.
- The post also recommends newsletters, Exercism.io, GitHub projects, Stack Overflow, Reddit, Google+, LinkedIn, the official install guide, Elixir Conf 2015, Planet Elixir, and the official Getting Started with Elixir tutorial.

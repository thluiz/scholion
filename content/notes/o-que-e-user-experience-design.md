A página usa uma citação de Whitney Hess para definir User Experience como algo que começa antes da solução. UX aparece como o processo de estabelecer qual problema precisa ser resolvido, para quem ele precisa ser resolvido e qual caminho deve ser seguido para resolvê-lo.

## Fichamento

- UX não é apenas encontrar a melhor solução para os usuários.
- O trabalho em UX começa pela definição do problema que precisa ser resolvido.
- Também envolve definir para quem esse problema precisa ser resolvido.
- UX inclui definir o caminho que deve ser percorrido para resolver o problema.

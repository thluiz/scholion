A Microsoft levou o Roslyn, projeto que reúne as novas versões de C# e VB, do Codeplex para o GitHub. O texto destaca que o repositório ficou sob a organização dotnet, ligada à .NET Foundation, e que issues, wiki e pull requests passam a ser acompanhados por lá.

O autor registra que as design notes do Codeplex talvez migrem para issues no GitHub, enquanto o Roslyn Reference Source continua no Codeplex. Ele lê a mudança como um passo natural da Microsoft em direção aos desenvolvedores e espera mais participação da comunidade no projeto.

## Fichamento

- O time de linguagens da Microsoft moveu o Roslyn do Codeplex para o GitHub.
- O projeto reúne as novas versões de C# e VB.
- O repositório ficou na organização dotnet, da .NET Foundation.
- Issues, wiki e pull requests agora ficam no GitHub.
- As design notes do Codeplex podem acabar em issues do GitHub.
- O Roslyn Reference Source continua no Codeplex.
- O autor entende a mudança como um sinal de aproximação da Microsoft com a comunidade de desenvolvimento.
- Ele espera mais comentários, pull requests e envolvimento no projeto.

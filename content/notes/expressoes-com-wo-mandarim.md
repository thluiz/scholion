Expressões cotidianas em mandarim no padrão **我 + verbo**, agrupadas por campo semântico. Lista de estudo expandida a partir de uma seleção do Reddit.

### Cognição

| 漢字 | Pinyin | PT |
|------|--------|-----|
| 我知道 | Wǒ zhīdào | sei |
| 我不知道 | Wǒ bù zhīdào | não sei |
| 我想 | Wǒ xiǎng | penso (também: quero) |
| 我认为 | Wǒ rènwéi | considero |
| 我以为 | Wǒ yǐwéi | achava (implica engano) |
| 我觉得 | Wǒ juéde | acho |
| 我懂 | Wǒ dǒng | entendo (informal) |
| 我明白 | Wǒ míngbai | entendo |
| 我理解 | Wǒ lǐjiě | compreendo |
| 我记得 | Wǒ jìde | lembro |
| 我忘了 | Wǒ wàngle | esqueci |
| 我学 | Wǒ xué | aprendo / estudo |
| 我认识 | Wǒ rènshi | conheço (pessoas) |

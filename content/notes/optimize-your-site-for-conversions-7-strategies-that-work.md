The page says a landing page has only a few seconds to turn visitors into signups, so the design should help people understand the offer, trust it, and complete the first step with little friction. It recommends matching the message to the audience, showing proof, leading with the action users actually want, and making the signup process pleasant on any device.

## Reading notes

- Make the value proposition clear right away and explain how the product or service improves the user’s life.
- Use testimonials and other proof to show what the customer can expect.
- Match language and visual tone to the audience you want to reach.
- Start with the core action the user wants, not with a generic signup request.
- Offer something in return for an email address, such as a discount, free shipping, a free trial, or educational content.
- Reduce friction by keeping forms simple, using clear labels, and validating errors inline.
- Design for mobile first, with large tappable fields and buttons that work well on phones.
- Ask for the minimum information needed at the start and collect the rest later.
- Use conversational interfaces when they fit the product and can help build a more human signup experience.

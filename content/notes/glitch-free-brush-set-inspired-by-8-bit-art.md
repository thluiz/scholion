The page presents the Glitch Brush Set as a free set for SketchBook users who want to sketch concept art faster. It is aimed at roughing out landscapes and cityscapes, and it uses intentionally malformed textures inspired by retro 8-bit video games and screen glitches.

The set is described as playful and useful for artificial or mirage-like landscapes. It combines pixels, glitches, flickers, and freezes, and the brush options can be blended to create both flat illustrations and more realistic scenes. The page also explains that SketchBook Pro members can install the weekly free brush sets in the desktop app, and that version 8 can install the .skbrushes file by double-clicking it.

Melanie Pinola summarizes Evan Miller’s argument that C is a better first language than Python for some beginners because it forces them to understand what the computer is doing underneath their programs. The piece frames this as a choice about the kind of mental model a new programmer builds.

## Reading notes

- The article says the best first programming language depends on goals and other considerations.
- Evan Miller argues for learning C first.
- He compares learning C first with learning to drive a stick shift.
- He says Python is convenient and a great advance over C, but teaching beginners Python can keep them from learning C later.
- He says knowing C is not required for a productive software career.
- He argues that Python is not challenging enough for people who might become the best programmers.
- He says C forces you to build a mental model of what the computer is actually doing.
- He says that model can grow to include the process model, CPU architecture, memory hierarchy, and operating system.
- He says that mental model, rather than C itself, helps you see through abstractions and write programs you did not think possible.
- The piece mentions Harvard’s CS50 as a course that starts with C.

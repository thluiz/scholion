## Reading notes

- A class is the definition or template of an object, while an object is an instance of that class, with its own properties, methods, states, and behaviors.
- Managed code is created by the .NET compiler and runs through the CLR, which provides garbage collection, type checking, and exception handling.
- Unmanaged code is compiled to native machine code, runs directly on the operating system, and requires the developer to handle memory usage, allocation, type safety, and exceptions manually.
- A while loop repeats code until a condition becomes true, while a for loop is used when the number of iterations is already known.
- Boxing converts a value type to object, and unboxing extracts the value type from the object; boxing is implicit and unboxing is explicit.

The author describes how modern software products heavily depend on open source tools and libraries that are usually created and maintained by hobbyists without financial compensation, while companies readily pay large license fees for proprietary enterprise software. He highlights the mismatch between willingness to pay for closed‑source tools and reluctance to donate small amounts to open source, then points to recent initiatives like GitHub Sponsors, Open Collective, and Formidable’s paid contribution program.

As a freelance developer, he wants to support open source beyond code contributions and decides to charge clients an extra 1 Euro per hour on future projects, up to about 160 Euros per month, and direct that money to the open source projects used in those client engagements via Open Collective. He mentions having considered this idea a year earlier, now committing to implement it, and encourages other developers to adopt similar practices so that open source work can become more sustainable when clients themselves do not fund it.

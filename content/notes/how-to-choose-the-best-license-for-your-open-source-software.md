The article says an open source project’s license affects more than legal formality. It shapes who can use the code, who will contribute, whether it can be incorporated into larger systems, and whether modified code must stay available.

It also says there are three broad license types, that cloud software can expose a source-code gap in some copyleft terms, and that project parts like images, sound, and video may need different licenses. It ends by recommending independent advice and careful reading before choosing.

## Reading notes

- A project can have strong code and still depend on its license choice for success.
- Some licenses can discourage use if people worry about incorporating the code into their own products.
- Releasing code with no license does not place it in the public domain; it remains copyrighted and others cannot reproduce, distribute, or create derivative works.
- An unlicense is presented as a way to place code in the public domain.
- Open source licenses are grouped into strong copyleft, weak copyleft, and permissive.
- Copyleft allows copying and sharing on the condition that the same distribution terms remain unchanged.
- GPL is given as an example of strong copyleft.
- LGPL is given as an example of weak copyleft and is used for libraries to allow non-free or closed source programs to use them.
- Permissive licenses allow more freedom, including adding proprietary features.
- MIT and Apache are listed as well-known permissive licenses.
- A permissive license may reduce outside contributions if developers do not want to support a commercial project.
- The GPL can create a source-code availability gap when software is offered as a service rather than distributed.
- AGPL is presented as a response to that gap by requiring source code access over a network.
- The article points to OSS Watch, GitHub’s Choose a License tool, and the Open Source Initiative’s licenses page.
- Images, sound, and video may need licenses such as Creative Commons.
- Independent advice and enough time to read the license terms are recommended before deciding.

The post argues that Divi’s default blog posts are weak and lays out a set of attributes for a better one: readable font size, controlled line height, black text, a line width of about 70 characters, a dropcap, a right-aligned opening image, and one image every 350 words. It then explains how to apply those choices in the Divi Customizer.

It also shows how to add dropcaps with a shortcode, recommends using images because they matter to readers, and points to Stocksnap and Canva as tools for finding or making them.

## Reading notes

- Default Divi blog posts are described as terrible, and the example layout is called underwhelming.
- The listed attributes for the perfect post are font size 16–22px, line height 1540–170%, font color #000, line width around 70 characters, a dropcap, a right-aligned image to start, and one image every 350 words.
- To implement the layout, the author changes Divi Customizer settings for sidebar width, body line height, text size, header size, header line height, bold header style, body text color, and meta font size.
- A dropcap can be created with a shortcode around the first letter.
- The article cites a study saying the top 100 blogs use an image every 350 words.
- The author says images are time consuming to make, but should still be used, and recommends the resource page, Stocksnap, and Canva.

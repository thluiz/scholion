Microsoft shared a vision for a new Windows 10 Start Menu that uses a transparent background and Fluent-based colorful icons. The goal is to make the Start Menu feel more uniform by blending the new icons with the existing layout.

## Reading notes

- Microsoft is exploring a Start Menu design with a transparent background for program tiles.
- The new Fluent-based system icons are part of the design changes being considered.
- Microsoft says the aim is to visually unify the Start Menu.
- Reports that Live Tiles are being removed are denied in the webcast.
- Brandon Leblanc said Live Tiles are not going anywhere right now.
- Users who rely on Live Tiles will be able to keep using them.

A AppGyver apresentou o Supersonic como um framework para construir apps híbridas para Android e iOS com “performance nativa real”. A proposta combina Ionic, Cordova e um wrapper próprio, com componentes nativos de interface, navegação e dados.

A entrevista explica que o Supersonic usa arquitetura multi páginas para evitar a limitação de uma única WebView e aproveitar a pilha de navegação nativa. O texto também descreve o Steroids, conjunto de ferramentas com CLI, Scanner, depuração, emuladores e build na nuvem.

## Fichamento

- O Supersonic é um framework da AppGyver para apps híbridas Android e iOS com promessa de performance nativa.
- Ele se apoia em Ionic e Cordova, mas acrescenta um wrapper próprio e componentes nativos de interface e navegação.
- A arquitetura multi páginas divide a app em vários documentos HTML e usa a navegação nativa para trocar de tela.
- A AppGyver afirma que isso evita o redesenho pesado do DOM ligado ao modelo de uma única WebView.
- O texto diz que barras, modals, tabs, drawers e transições são nativas.
- O framework é descrito como agnóstico, com exemplos e diretrizes para AngularJS.
- O Supersonic Data oferece ligação de dados de três vias e funciona com qualquer backend REST.
- O Steroids é o ferramental do projeto e inclui CLI em Node.js, geração de projeto, depuração, emuladores, logs e gestão de dependências.
- O app Scanner permite testar no dispositivo sem abrir Xcode ou Android Studio, inclusive para desenvolvimento iOS no Windows e Linux.
- O Build Service publica a aplicação na nuvem e gera binários para envio às app stores.
- Entre os planos futuros estão builds locais, mais recursos no Supersonic Data e suporte integrado a notificações push.

AskQL is presented as an open source query and programming language built to make flexible distributed software easier and faster to deliver. The page says it is asynchronous by default, processes only immutable data, and follows the functional programming paradigm.

The language uses AskScript for queries, with a low learning curve for people who know JavaScript or GraphQL. Requests go to AskVM, a secure sandbox on the server side that interprets each request and controls access through schemas and security policies. The text also says AskQL reduces the need for multiple API endpoints, offers a lightweight standard library in AskCode, and is published under the MIT license.

## Reading notes

- AskQL is described as a complete open source query and programming language for flexible distributed software.
- It is asynchronous by default, works with immutable data, and is based on functional programming.
- AskScript is the query language used with AskQL, and it is described as easy to learn for JavaScript or GraphQL users.
- AskVM runs on the server side as a secure sandbox and handles each request individually.

- AskQL’s standard library is written in AskCode to keep the system lightweight.
- The project is published under the MIT license and accepts contributions on GitHub.

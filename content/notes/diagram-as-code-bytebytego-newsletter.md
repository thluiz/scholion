The page collects six ways to create diagrams from code or text. It points to Diagrams for Python cloud architecture diagrams, Mermaid for diagrams and flowcharts from text, ASCII editors, PlantUML for plain-text diagrams, Markmap for Markdown mindmaps, and Go diagrams for system diagrams in Go.

## Reading notes

- Diagrams turns Python code into cloud system architecture diagrams.
- Mermaid generates diagrams and flowcharts from text in a Markdown-like style.
- ASCII editor tools listed are Asciiflow, dot-to-ascii, and Monodraw.
- PlantUML is described as an open source tool for creating diagrams from a plain text language.
- Markmap visualizes Markdown as mindmaps and supports a VS Code plugin.
- Go diagrams creates system diagrams with Go.

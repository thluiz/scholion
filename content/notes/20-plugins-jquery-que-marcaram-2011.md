O texto compila 20 plugins jQuery que se destacaram em 2011, com foco em ferramentas para interface, formulários, imagens, animações e visualização de dados. O jQuery Mobile aparece no topo como uma das ferramentas mais importantes do ano, seguido por opções voltadas a listas, modais, upload, sliders, layouts fluidos e avaliações.

## Fichamento

- jQuery Mobile lidera a seleção por oferecer uma API simples para dispositivos móveis, código quase todo em HTML e suporte total a operações com toque.
- Quicksand permite ordenar e filtrar itens de uma lista com animações e transições.
- Reveal simplifica a criação de janelas de alerta e informação, com uso direto via jQuery ou pelo atributo data-reveal-id.
- jQuery File Upload dá suporte a múltiplos envios, drag and drop, barra de progresso, cancelamento, restrições por tipo de arquivo e preview de imagens.
- QapTcha troca o captcha tradicional por um slider de liberação.
- DropKick facilita a criação de menus dropdown e entrega bom resultado em todos os navegadores.
- ParallaxSlider nasceu de um tutorial e propõe uma galeria de fotos com background acompanhando a navegação.
- Toast Message exibe mensagens informativas no formato popularizado pelo Growl.
- FitText ajusta o tamanho de títulos e textos conforme o elemento pai.
- jRumble adiciona efeitos de tremer, vibrar, balançar ou girar em elementos, com controle de opacidade e velocidade.
- Mosaic permite criar boxes deslizantes de fotos ou conteúdo, com animações e tooltips.
- Isotope cria layouts fluidos com animações e transições personalizadas.
- Zoomooz também trabalha com layouts fluidos, mas acrescenta zoom.
- jQuery uCompare mostra comparações de antes e depois com visualização dinâmica pela posição do mouse.
- ArborJS é voltado à visualização de grafos e traz uma API rica para manipular itens e o grafo.
- Slides é apresentado como um plugin de slideshow com simplicidade de implementação e personalização.
- Zoomy oferece uma ferramenta de zoom em imagens, simulando a lente da Apple, com callbacks para personalização.
- jFormer busca facilitar a criação de forms bonitos, paginados e com validações integradas.
- DynamicNews integra um ticker de notícias com funções de anterior e próxima e tooltips.
- jRating permite criar um sistema de votação com jQuery e AJAX, com configuração de estrelas e callbacks onSuccess e onError.
- jQuery Boilerplate funciona como template inicial para criar plugins jQuery e é indicado como base para desenvolvedores.
- Create é apontado como uma interface de edição de conteúdo inline para 2012.
- nanoScroller oferece um scroll simples com visual inspirado no Mac OS.

The post asks whether web frameworks still matter in the age of agentic programming and concludes that they do. It argues that if you do not use an explicit framework, an LLM will create an implicit one anyway, so the real question is what kind of framework should shape the work.

It treats frameworks as providers of abstractions, structure, and constraints, and says those qualities are still useful when building with agents. The author also says there is still room to improve on existing options and that new frameworks can matter if they help AI produce code that is easier to reason about.

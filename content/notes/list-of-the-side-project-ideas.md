A list of side project ideas meant for portfolio building, job preparation, and coding practice. The suggestions span web apps, mobile apps, APIs, CLI tools, bots, and infrastructure-like projects.

## Reading notes

- Build a virtual museum tours app or website that gathers many online tours, possibly with VR support.
- Make an app for watching a movie online with friends, including support for different audio tracks and subtitles.
- Create a tool that estimates calories from a food photo, preferably as a mobile app.
- Build a map-based social network for chatting with people near you.
- Create a shared authentication and authorization service that other apps can use through an API.
- Build an encryption and decryption app or API for plain text and files.
- Make a finance forecaster that predicts future income and expenses from current data, possibly using machine learning.
- Create a virtual banking system for sending and receiving payments, with a new digital currency.
- Build a 2D or 3D map generator for games.
- Make photo storage software, possibly self-hosted.
- Create a pixelizing image tool that reduces image resolution into pixels.
- Build a daily learning app that sends useful material on chosen topics.
- Write your own Git as a CLI tool.
- Build an alternative to the BitTorrent protocol.
- Make a simplified universe simulator that models how quarks interact.
- Create a CLI task tracker for tasks or projects.
- Build messenger bots for conversation, random chat, daily vocabulary, mood guessing, photo recognition, game advice, trivia matches, and book splitting.

The piece argues that business readers need to understand software because technology and business are becoming more intertwined while many business people remain disconnected from how software evolves. It uses GitHub as an example of a tool that matters beyond the developer world.

## Reading notes

- GitHub is presented as a community built around Git, and Git is described as a distributed version control system that lets people work locally without needing a server for every step.
- GitHub is defined by sharing code and working with other people, whether the code goes to a stranger, a friend, or a co-worker.
- The platform is said to make it easier and faster to start projects, which leads people to create more of them, from small config files and tiny experiments to large open source projects.
- GitHub is described as useful for hiring because it shows what people have actually worked on, not only what they claim on a resume or profile.
- Chris Wanstrath says more non-programmers will learn to code so they can automate repetitive tasks and build their own apps.
- He says idea generators will increasingly build prototypes themselves and pitch with demos instead of slides.
- He rejects the 10x developer theory and says the best developers are curious, passionate, and always learning.
- GitHub Enterprise is presented as part of an effort to serve both large corporations and people building prototypes on nights and weekends.
- Wanstrath says programming will get easier to start learning, helped by education sites like Codecademy and by the growing role of software in everyday life.
- He suggests the near future will bring more programming use from writers, customer support workers, and teachers, who can customize browsers or write small apps to improve their workflow.

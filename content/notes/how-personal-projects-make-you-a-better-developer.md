Personal projects are presented as a way to keep learning after work, even when programming feels tiring. They let you try frameworks, libraries, and ideas that matter to you, while giving you room to work on something that feels fun.

## Reading notes

- Personal projects let you experiment without approval or consequences, so you can try new tools, write messy code, or stop if a framework does not suit you.
- Working alone on a project teaches more of the application lifecycle, including architecture, tech stack choices, hosting, and resource needs.
- Personal projects make room for creativity and for ideas you would not use at work, including trying different programming styles or building something you wish already existed.
- If you cannot settle on an idea, the text suggests starting by recreating an existing app with a different stack so you can begin and discover what you actually want to build.
- The author says even short, regular time on a project still counts because it leads to learning and keeps curiosity about code alive.

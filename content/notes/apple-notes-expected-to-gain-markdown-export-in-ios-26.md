Apple Notes is rumored to get limited Markdown support in iOS 26 and macOS 26. According to the report, the change would let users export text in Markdown format, but not write notes in Markdown directly.

If the rumor is accurate, Apple could show the feature at next week’s Worldwide Developers Conference, alongside other iOS 26 changes such as automatic translation and polls in Messages.

The post says a bullet journal can start to feel boring after using simple black-pen spreads for a while. It lists seven quick ways to change that without taking up much space, using highlighters, washi tape, dual tip pens, lines, symbols, icon stickers, and stamps.

## Reading notes

- Dual tip highlighters add color and help divide the page, mark titles, draw borders, underline headings, and create check boxes.
- Frixion highlighters are suggested if you want something erasable, and the bright versions are recommended over the pastel ones.
- Thin washi tape is preferred because bullet journal notebooks are small, and it can divide trackers, weekly spreads, lists, titles, and page edges.
- Dual tip pens create contrast, with the thicker end used for headings and checkboxes and the thinner end for writing.
- Different kinds of lines and pattern borders can make page dividers less plain, and writing on every second line is used to keep the layout neat.
- Symbols can replace repeated category names in planning lists when there are many planning categories.
- Icon stickers are presented as a quick way to code tasks, save time, and avoid writing tasks out repeatedly.
- Stamps are used less often by the author because they take effort and can be messy, but self-inking Frixion stamps are mentioned as useful for list making and habit tracking.

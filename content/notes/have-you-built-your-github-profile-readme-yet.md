GitHub now offers a profile-level README that appears prominently on a user profile. The article explains the setup steps: create a public repository with the same name as your GitHub account, initialize it with a README, then edit it with the content you want to show.

## Reading notes

- Create a public repository whose name matches your GitHub username.
- Initialize the repository with a README.
- Edit the README and add the content you want to display.
- The README can include a short bio-type intro.
- You can upload images, gifs, and badges for other social media accounts.
- Adding these elements changes how the profile looks.
- Social media badges can be added to make the layout look more fascinating.

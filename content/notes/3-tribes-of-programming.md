The essay says programming is understood through three ideals. One group treats code as mathematical thought, one treats it as hardware hacking, and one treats it as a practical way to make things for other people. These ideals shape languages, conferences, heroes, and arguments about what good software is.

## Reading notes

- The first tribe sees programming as an expression of thought, like mathematical poetry, and values terse source code, formal correctness, high-level languages, and code beauty over UI.
- The second tribe ties programming to the machine itself, values clear execution and performance, prefers low-level languages, and treats hardware-aware efficiency as central.
- The third tribe sees software as a tool for people, values usability and shipping products, and judges code by its usefulness, speed, and impact on users.
- The essay links common debates, such as integer overflow, garbage collection, abstraction, and Rust, to these different priorities.
- It argues that many conflicts in programming come from people judging “good” software by different tribal standards.
- It closes by saying programmers should learn from each other across the three camps, and that people like Grace Hopper and Alan Kay bridge these perspectives.

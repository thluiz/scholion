The page revisits Beatrice Warde’s idea that good typography should be invisible, then argues that this only fits some kinds of text. On the web, body copy may call for type that recedes, but logotypes, buttons, layouts, tables, and forms can require type that is visible and expressive.

Legibility is treated as a basic requirement, not the main measure of typographic quality. The page says type can add flavor, make content pleasurable, and serve different goals across different kinds of work, which is why making everything invisible is too simple.

## Reading notes

- Warde’s 1955 talk, later published as “The Crystal Goblet, or Printing Should Be Invisible,” presents good typographic design as something that should not be seen.
- The page disagrees with the idea that type should always be invisible and says it should instead be appropriate to the content.
- On the web, body copy is often treated as the main case for invisible type, because long-form text should be easy to read.
- Not all typography is body copy; logotypes, buttons, rich layouts, data tables, and forms also depend on type.
- Legibility is described as a baseline requirement, like edible food or audibility in speech, not as the full measure of good typography.
- Different typefaces bring different characteristics that flavor words and can move text from merely legible to pleasurable.
- The page agrees with Nick Cox that visible typography has merit when a competent typographer makes a text sing.
- It closes by rejecting a reductionist UI ideal that tries to make everything invisible.

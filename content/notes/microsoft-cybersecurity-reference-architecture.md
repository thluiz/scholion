The Microsoft Cybersecurity Reference Architecture (MCRA) is a broad set of technical architectures to support Zero Trust security adoption and modernization across hybrid, multicloud, legacy IT, OT/IoT, AI, and more. It is part of the Microsoft Security Adoption Framework and is intended to speed planning and execution of security modernization using open standards, Microsoft solutions, and third‑party tools. The latest version was released in June 2026, with updates to menus, diagrams, role guidance, AI content, standards mappings, and new Microsoft services.

- The architectures aim to accelerate planning and execution of security modernization using open standards plus Microsoft and third-party security technologies.
- MCRA is a component of the Microsoft Security Adoption Framework (SAF), which provides a standardized process to plan, prioritize, design, and implement security modernization based on Zero Trust principles.

The article argues that AI does not remove work for software engineers. It moves effort toward supervision, code review, task switching, and repeated decisions, which can make the workday feel denser and more tiring.

## Reading notes

- AI tools can increase output, but many developers still end the day more tired.
- The work shifts from typing code to supervising agents, checking results, and deciding what to do next.
- Supervising AI never really pauses, unlike earlier work that had natural breaks during compilation or test runs.
- The article distinguishes fatigue, burnout, and “AI brain fry.”
- Fatigue is tiredness after sustained effort and may improve with sleep or a lighter week.
- Burnout is a longer-term state marked by drained energy, cynicism, and reduced effectiveness.
- “AI brain fry” names the mental fatigue from rapidly supervising AI tools.
- Multiple agents in parallel create more switching between tasks and projects.
- Reviewing AI-generated code still requires judgment, even when the code is good.
- Faster code generation means more frequent review and more decisions in a shorter time.
- Kanban limits are suggested to avoid too many tasks in parallel.
- The article also recommends regular breaks and a hard stop after work, such as a gym or dance class.

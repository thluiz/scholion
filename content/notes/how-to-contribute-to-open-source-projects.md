The article argues that contributing to open source makes you a better developer and can also help with hiring and long-term recognition. It says the work is not just charity, since it can build skills, create opportunities, and shape a programming legacy.

## Reading notes

- Open source creates pressure from real users, which helps sharpen developer skills.
- Companies may use open source contributions when deciding whom to hire.
- Contributing is not only unpaid charity; it can help you sell yourself professionally.
- A strong project choice starts with something that solves a problem you care about.
- Good projects are active, maintain their issues list, and have a useful wiki.
- Small contributions are acceptable if they add value and are explained clearly.
- A pull request works better when it starts a conversation instead of just asking for a merge.
- Open source also involves community participation, not only code.
- People can bring value through language skills, event hosting, or other non-code help.
- Asking for help is part of the process, and many contributors are willing to help.

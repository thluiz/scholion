YouTube says it is launching 60fps live streaming as an early preview on HTML5-compatible browsers. Streams are transcoded into 720p60 and 1080p60, with 30fps playback offered on devices that do not yet support high frame rate viewing.

The post says high frame rates matter especially for gaming streams. It mentions updated versions of Elgato Game Capture, XSplit Broadcaster, and XSplit Gamecaster, plus a new high frame rate flag for apps using the live streaming API. It also says YouTube live streams now use an HTML5 player in supported browsers, which allows variable speed playback and rewinding while a stream is live.

## Reading notes

- 60fps live streaming starts as an early preview on HTML5-compatible browsers.
- YouTube transcodes 60fps streams into 720p60 and 1080p60.
- Devices without high frame rate support can still watch the stream at 30fps.
- Updated versions of Elgato Game Capture, XSplit Broadcaster, and XSplit Gamecaster support 60fps live streaming to YouTube.
- Apps using the live streaming API can use a new high frame rate flag to enable 60fps streaming.
- YouTube live streams now use an HTML5 player in supported browsers.
- The HTML5 player supports variable speed playback, including going back while a stream is live and watching at 1.5x or 2x speed.

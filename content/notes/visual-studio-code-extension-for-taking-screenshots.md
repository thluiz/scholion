The post starts from a common need in documentation and blog writing: taking screenshots of code. It points out that Carbon is a popular option, but it requires copying code into an external site and adjusting the appearance there.

It then presents Polacode as a Visual Studio Code extension that lets you capture screenshots directly from your editor. The steps are to install it from the marketplace, configure a few basic options such as background color or transparency, open the Command Menu, select the code, and save the generated image.

## Reading notes

- Carbon is described as a widely used site for code screenshots, with controls for fonts, syntax highlighting, background color, and export to PNG or SVG.
- The main drawback of Carbon in the post is that the code has to be copied from the editor to an external site.
- Polacode is introduced as a Visual Studio Code extension for taking screenshots from the editor itself.
- Installation is done through the Visual Studio Marketplace by searching for Polacode.
- The extension offers only a few settings, including background color and transparent background.
- To use it, the user opens the Command Menu, writes Polacode, selects the code to show in the preview, and clicks the Screenshot button.
- The post says this shortens the time needed to create screenshots for personal branding and blog posts.

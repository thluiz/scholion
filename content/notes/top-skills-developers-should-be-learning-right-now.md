The article says web development changes fast, so developers should keep watching technologies that are gaining traction or reshaping how teams build software. It highlights language, framework, deployment, and design skills that look especially worth learning.

## Reading notes

- ECMAScript 6 adds classes, for/of loops, new iterators, modules, and arrow functions, and much of it can already be used in modern browsers.
- Go is gaining traction among engineers, has a growing community, and is showing up more in production use and job listings.
- React is emerging as a strong alternative to Angular for JavaScript applications, with unidirectional data flow and support for modular code structure.
- Vagrant and Docker help create reproducible, portable work environments and can also support deployment to production.
- Design thinking is changing how companies approach product design by treating designers as key members of the development team.
- AB testing, instrumentation, and lean collaborative design are becoming part of the development workflow.
- Web developers are encouraged to study user-centered design principles, join user testing, and pay attention to customer experience.

ParamQuery Grid is presented as a lightweight jQuery grid plugin inspired by MS Excel and Google Spreadsheet. It is built on jQuery UI Widget Factory and is described as free for commercial and open source use under the MIT license.

## Reading notes

- The grid supports sorting, paging, resizable columns, and resizable height and width.
- It includes customizable themes and the ability to hide or show columns.
- It can freeze any number of columns like Excel.
- It accepts HTML, Array, XML, JSON, and other data source formats.
- It can be used with server-side frameworks such as ASP.NET, MVC3, JSP, JSF, and PHP.
- It supports virtual scrolling and rendering.
- It allows inline editing of cells.
- It is described as working consistently across major browsers including IE 6+, Firefox, Chrome, and Opera.

The page collects viewpoints on programming fonts and compares them by legibility, how they distinguish easily confused characters, how much space they take, and whether they work well on specific systems or renderers. It also points to download sources and mentions several fonts that are bundled with operating systems or editors.

## Reading notes

- Source Code Pro is an open source font from Adobe, available on Google Web Fonts, made to maximize usability and avoid common monospaced font design flaws; it lacks italics.
- Consolas comes with Windows and is designed to work with ClearType, so it can look highly aliased without ClearType.
- Monaco is presented as a favored choice, with screenshots but no further explanation.
- Inconsolata-g is a variant of Inconsolata that fixes the similarity between 1 and lowercase l.
- Ubuntu Mono is praised for its rounded look and for staying legible at very small sizes with subpixel rendering.
- Anonymous Pro is a fixed-width family designed for coding, with distinct shapes for characters that are easy to confuse.
- DejaVu Sans Mono is described as an open source family derived from Bitstream Vera and close to Andale Mono, with bold text staying the same width as regular text.
- Menlo is a monospaced sans-serif typeface that first shipped with OS X Snow Leopard and is based on Bitstream Vera and Deja Vu.
- Envy Code R distinguishes programming characters clearly, stays narrow, and keeps bold at the same width as normal text.
- Droid Sans Mono includes versions with slashed or dotted zeros.
- Pragmata Pro is narrow, highly legible, and includes substantial Unicode support, including APL codepoints.
- Liberation Mono is intended as a free replacement for closed source fonts, takes less vertical space than DejaVu, and is praised in a quoted comment for readability and useful glyph shapes.
- Monofur is shown with screenshots and a download link, but no descriptive text beyond that.
- Terminus is a small bitmap font with a download link and a note that the screenshots are at 11pt.
- Andale Mono was offered by Microsoft as a core Web font and is noted for distinguishing characters like 0, O, 1, l, and I.
- Meslo LG is a customized version of Menlo-Regular, with screenshots and a download link.
- Dina is a monospace bitmap font aimed at programmers, designed to distinguish similar letters and digits and to keep braces aligned.
- Lucida Console is said to distinguish brackets, commas, and periods even at 8pt and to come with every Windows box.
- Proggy Clean is presented as a small bitmap font for programming.
- The M+ fonts are described as balancing natural letterforms and high legibility, with separate monospace forms and weights.
- PT Mono has screenshots and a Google Web Fonts download link.
- Segoe UI Mono comes with Windows and may need Office or @font-face on Mac.
- TheSans Mono is described as a monospace family derived from TheSans, with hand-pixeled bitmaps for common sizes and use in O'Reilly books.
- Gohufont is a monospace bitmap font for programming and terminal use, intended to be very legible.
- Latin Modern Mono is based on Computer Modern, includes many diacritical characters, and is available in several variants.
- 6x13 fixed is described as a classic fixed monospace bitmap font for X servers, with readability and predictable terminal dimensions emphasized.
- Espresso Mono is included in the Espresso editor and its metadata says it was designed by the DejaVu fonts team.
- Panic Sans is described as close to Source Code Pro and Inconsolata, with better line spacing and italics.
- Anka/Coder is a courier-width family for source code and terminal windows, with regular, italic, bold, and bold-italic sets.
- Nanum Gothic Coding is shown with screenshots and a download source, but the text only says the font looks beautiful.
- ProFont is a small bitmap font made for Macintosh and now available on Windows and Linux/UNIX X Windows.
- Cruft is a variable-width programming font meant to keep characters distinguishable and punctuation prominent.
- Print Char 21 is described as a TrueType Apple II font for Mac OS X, Windows, or any TrueType system.
- VGA Font is presented as a Unicode-supported version of the original VGA font, used in Visual Studio with a classic blue background.
- Envy Code B is listed with a screenshot but no descriptive text.
- Raize is described as a clean, crisp fixed-pitched screen font suited to programming and other text work.
- Triskweline is a fixed-width font for editors and programming environments, designed for legibility and tidiness.
- OCR A Extended is preferred because its characters remain distinct, including apostrophes and quotes.
- The page ends by asking if something is missing and inviting more contributions.

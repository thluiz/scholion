Realm launches a Xamarin-specific mobile database for .NET developers. It keeps the object-based approach of the other Realm editions, adds live objects and change events, and is meant to support reactive app development and unidirectional data flow.

## Reading notes

- Built specifically for Xamarin, with C# code that becomes native iOS and Android apps
- Offers easy object persistence and full query capabilities
- Says its performance profile is faster than existing options
- Includes live objects, change events, and support for unidirectional data flows
- Uses native C# objects mapped to a custom database engine rather than SQLite or an ORM layer
- Lets developers model complex data, link objects in graphs, and compose advanced queries with LINQ
- Targets Xamarin.iOS and Xamarin.Android, with future support planned for Xamarin.Mac, UWP, and Unity
- Says Realm can be used in one codebase for both iOS and Android, and that the file format is cross-platform
- Presents Realm as easy, fast, trusted, community-driven, and supported
- Notes benchmark tests from May 9, 2016 and recommends testing real use cases independently
- Asks for feedback, bug reports, and feature requests on GitHub

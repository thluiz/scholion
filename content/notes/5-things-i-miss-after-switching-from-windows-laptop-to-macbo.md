The author says the MacBookPro has been mostly satisfying, but still lacks a few Windows conveniences he used often. The missing features are tied to multi-monitor window handling, desktop and window management, keyboard hardware, and language switching.

## Reading notes

- He misses being able to stretch one application window across two monitors, especially with Chrome DevTools on one side and the main browser window on the other.
- He also wants a true “minimize all windows” shortcut like the Windows show-desktop behavior.
- On macOS, he finds it inconvenient that the Dock is visible on only one screen at a time instead of every display.
- He notes that the Mac keyboard does not have a dedicated Delete key with the same behavior as on PC keyboards, and uses fn+Delete instead.
- He misses PuntoSwitcher for correcting keyboard layout mistakes across more than two languages; on Mac, he says it only works between two chosen languages.
- He says these limitations are not a disaster, and he still keeps using the MacBookPro.

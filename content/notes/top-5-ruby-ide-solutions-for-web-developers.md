The post lists five Ruby IDE options for web developers and explains that many of them are not limited to Ruby alone. It also notes that the author chose tools that are either widely used or frequently updated, and that some can be extended with plugins.

## Reading notes

- Many web developers start with Notepad++ or Notepad, even though tutorials increasingly use interactive editors.
- Most Ruby IDEs are not limited to Ruby and are offered as standalone plugins or broader development environments.
- Aptana Studio 3 includes HTML, CSS, and JavaScript support, can deploy to major hosting platforms, and integrates Git.
- RubyMine 6 is presented as a modern Ruby IDE with a 30-day trial, paid plans, multiple-project support, Zeus functionality, and full Rails integration.
- NetBeans no longer ships Ruby IDE support directly, but a Ruby and Rails plugin provides a full IDE solution.
- Komodo supports Ruby along with other languages such as Node.js and CoffeeScript, offers many features, and has pricing after a trial, with free use for open-source and non-profit projects.
- Arcadia is written in Ruby for Ruby, supports no other languages, and has remained in beta since 2010.

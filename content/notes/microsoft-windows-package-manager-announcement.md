Microsoft announced a preview of Windows Package Manager at Build 2020. It is an official command-line package manager for Windows that lets users install tools with one command, and its package repository is open source.

## Reading notes

- The tool is available through the open source GitHub repository, Windows Insider rings, or the Windows Package Manager Insider program.
- After joining an Insider program, users should get the App Installer from the Microsoft Store to access the package manager update.
- Microsoft says the package manager checks each manifest with SmartScreen, static analysis, SHA256 hash validation, and other processes.
- The article says Microsoft is building it partly for security, and notes uncertainty about how it will compete with Chocolatey.

Microsoft’s Windows Phone 7 is presented as a new mobile OS that brings contacts, photos, music, video, web content, applications and services into one view. The post describes a Start screen built from live tiles, social networking built into the system, and integrations with Xbox Live and Zune.

## Fichamento

- The system is described as a way to gather contacts, photos, music, video, web content, applications and services into a single mobile experience.
- The Start screen can be customized with live tiles that show updates from the web.
- The home screen gives access to contacts, web content, social networking services and local applications.
- The post says the interface uses large icons and large text, with sliding transitions between views.
- It states that Windows Phone 7 is a new OS with fresh underlying code, not just a new skin.
- Social networking is integrated into contact pages, with status updates from multiple services and quick access to cloud content such as photo galleries.
- Xbox Live integration adds games, avatars and profiles.
- Zune features are built into the OS, and the interface is said to be familiar to Zune users.
- The hardware section says all devices will share specific CPU, screen ratio, resolution, memory and button configurations.
- It says the devices will not use UI customizers like Sense or TouchWiz, and that this will make Windows Phone 7 devices look similar at first sight.
- The post lists carrier and hardware partners, including AT&T, Verizon Wireless, HTC, Samsung, Dell, LG and Qualcomm.
- The closing paragraph frames Windows Phone 7 as Microsoft’s new entry into the smartphone competition alongside iPhone OS, Android, Blackberry and Palm.

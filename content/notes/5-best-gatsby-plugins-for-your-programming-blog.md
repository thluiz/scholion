GatsbyJS is presented as a static site generator for fast blogs and websites, built on React and easy to start from a starter template. The article then lists five plugins the author uses on his own sites to add code highlighting, analytics, PWA features, JSON-driven content, and document head control.

## Reading notes

- GatsbyJS is described as a static site generator for fast blogs and websites.
- The author says GatsbyJS is popular together with Hugo and Jekyll, and that he prefers it because it uses React.
- Starter templates can get a blog running in about five minutes, then the code can be pushed to GitHub and deployed to Netlify.
- gatsby-remark-prismjs is recommended for syntax highlighting in programming blogs, with PrismJS choices available on its website.
- gatsby-plugin-google-analytics connects a GatsbyJS site to Google Analytics and includes an OutboundLink component for tracking clicks on outbound links.
- gatsby-plugin-manifest helps set up a manifest, customize splash colors, autogenerate icons, and let users add the site to the home screen as a PWA.
- gatsby-transformer-json is used when configuration data is stored in JSON files, such as products, team members, or testimonials, and then pulled into pages dynamically.
- gatsby-plugin-react-helmet adds support for React Helmet so the document head can include metadata such as title, description, and shared images.
- The article says these are the author's five favorite GatsbyJS plugins and invites readers to suggest others in the comments.

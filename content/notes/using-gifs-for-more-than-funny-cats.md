The post argues that GIFs are useful for motion-graphics feedback in Basecamp because they are easier to review than large video files. It says they autoplay, loop, and make it simpler to compare several versions at once. It also notes the production workflow: render in After Effects, bring the file into Photoshop, and save it as a GIF.

## Reading notes

- GIFs can be used for motion-graphics feedback instead of uploading full video files to Basecamp and waiting for notes.
- They autoplay and loop, so the viewer does not need to open a large video file in a new window.
- Multiple versions can be viewed together.
- The process described is rendering in After Effects, moving the result into Photoshop, and saving it as a GIF.
- For the 1080p videos mentioned, the GIFs were saved at 300×169 with 16 colors.

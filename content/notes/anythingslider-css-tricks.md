AnythingSlider is presented as a jQuery slideshow for HTML content. The page lists support for multiple sliders on one page, infinite continuous sliding, optional resizing per panel, arrows, keyboard navigation, tabbed navigation, hash links to specific slides, autoplay, hover pausing, and stop-at-end behavior.

## Reading notes

- Panels can contain HTML content.
- Multiple AnythingSliders can appear on the same page.
- Sliding can continue in one direction even at the last slide.
- Each panel can be resized through CSS.
- Next and previous arrows are optional.
- Keyboard navigation and dynamically built tabs are supported.
- Static links can jump to a specific slide or move one slide forward or back.
- Each panel gets a hashtag that can link directly to it.
- A custom formatter can change the navigation text.
- The slideshow can autoplay, start stopped, pause on hover, stop at the end, and play right-to-left.
- YouTube videos can pause when out of view and resume when visible in supported browsers.
- The page includes default options for size, navigation, autoplay timing, easing, and text labels.
- Usage examples show how to read the current slide, set a slide from an external link, and control start, stop, forward, and back programmatically.
- The changelog records added options, CSS and resizing changes, keyboard navigation, hash URL support, and accessibility improvements.

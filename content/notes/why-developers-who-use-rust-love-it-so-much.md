Rust was once again the most loved language in the 2020 Developer Survey, with most current users saying they want to keep using it. The post gathers comments from Rust users and Rust team members to explain that response through the language’s safety guarantees, tooling, ecosystem, and developer experience.

## Reading notes

- Rust has been the number one most loved language since 2016, and 86.1% of current users said they want to keep using it next year.
- Users describe Rust as a language that introduces genuinely new features, especially memory safety in a compiled systems language without garbage collection or a complicated runtime.
- Several comments focus on compile-time guarantees that cover types, thread safety, ownership, validation, and interface use.
- Users praise Rust for reducing boilerplate, making refactoring safer, and turning many mistakes into compile-time errors instead of runtime errors.
- The language is described as combining low-level control with high-level expressiveness, while staying uniform and consistent across codebases.
- Cargo, crates.io, Rustup, inline documentation, tests, benchmarks, and cross-compilation are presented as major reasons users like the ecosystem.
- Some users say Rust is challenging to learn, especially because concepts like ownership do not map cleanly from other languages, but they still find the effort worthwhile.
- Rust team members say the language’s appeal also comes from a respectful community, a flexible project structure, and a positive way of presenting the language instead of framing it as a replacement for other languages.
- The post notes that only a small share of survey respondents had used Rust recently, but that the users who do choose it often want to continue using it.

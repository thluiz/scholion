This page lists browser features that can help while developing web applications. It focuses on practical DevTools actions in Chrome, from inspecting colors and editing animations to checking coverage, rendering, dark mode, sensors, and keyboard shortcuts.

## Reading notes

- Shift-click a color swatch in DevTools to see its hex, rgb, and hsl values.
- Use the animation editor to choose predefined timing functions and slow animations down for debugging.
- Adjust box-shadow and text-shadow with the inline shadow editor.
- Open the Command tool with Cmd+Shift+P to access files and actions.
- Search the Command tool for coverage to check CSS coverage.
- Search the Command tool for rendering to inspect FPS, layout, and paint.
- Use the emulator to switch between dark and light mode.
- Open sensors from the Command tool to change location for location-based experiences.
- Use Cmd+L to go to the address bar, Ctrl+Tab to move through tabs, and Ctrl+number keys to jump to tabs, with Ctrl+1 and Ctrl+9 for the first and last tab.

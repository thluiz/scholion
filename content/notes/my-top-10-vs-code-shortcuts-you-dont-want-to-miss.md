The author says he relies on keyboard shortcuts while coding and picks ten VS Code shortcuts he uses most. The list focuses on moving quickly between edit locations and files, jumping to matching brackets or tags, selecting code inside brackets, and handling imports and explorer navigation more efficiently.

## Reading notes

- Go to last edit location helps return to the place where editing stopped after checking other files.
- Go to bracket jumps from an opening bracket to the matching closing bracket, or back the other way.
- Select to bracket selects everything inside brackets and can be enabled with a custom keybinding.
- Go to matching pair jumps to the matching tag and is useful while editing React components.
- Go to the previous file returns to the file opened before the current one, even when cursor history does not help.
- Go to symbol in editor jumps directly to a function or other symbol by name.
- Toggle column selection mode helps edit several consecutive lines with keyboard selection.
- Focus on Files Explorer highlights the current file in the explorer so it can be renamed or used to create files nearby.
- Organize imports removes unused imports and reorders the remaining ones.
- Add all missing imports uses quick fix to insert missing import statements in TypeScript files.

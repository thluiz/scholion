A página descreve o sitemap como uma forma simples de informar os motores de busca sobre as páginas disponíveis para indexação. Também afirma que ele ajuda os buscadores a encontrar páginas mais rápido, mas não garante indexação nem melhora de posição.

## Fichamento

- Um sitemap serve para comunicar aos motores de busca quais páginas do site estão disponíveis para indexação.
- O padrão foi definido por Google, Microsoft e Yahoo, o que ajuda os buscadores a localizar páginas mais rapidamente.
- O arquivo deve conter URLs válidas, porque ele é lido por robôs e URLs incorretas podem afetar a autoridade do site.
- Cada sitemap tem limite de tamanho, com recomendação de menos de 50 MB ou até 50 mil URLs por arquivo.
- Todas as URLs precisam estar no mesmo host, e o tamanho máximo de uma URL é de 2.048 caracteres.
- A tag loc aponta para a URL da página.
- A tag lastmod informa a data da última modificação da página.
- A tag changefreq indica a frequência média de atualização da página.
- A tag priority permite indicar a importância relativa de uma página, de 0,0 a 1,0.
- Um índice de sitemaps pode reunir vários arquivos em um só envio ao Google.
- Há sitemaps específicos para Google News, vídeo, imagens e celular.
- O sitemap de notícias é voltado para grandes portais com muitas URLs e atualizações constantes.
- O sitemap de vídeos aceita formatos como WMV, MP4, MPEG, MPG, m4v, asf, fvl, swf, avi, RA e RAM.
- O sitemap de imagens pode trazer tráfego extra por buscas de imagens no Google.
- O sitemap para celular é apresentado como uma forma de acompanhar o crescimento das buscas em dispositivos móveis.
- O Google Webmasters Tools permite testar o sitemap antes do envio.
- Se o site tiver feed RSS ou Atom, a URL desse feed também pode ser enviada como sitemap.
- Também é possível criar um arquivo TXT com uma URL por linha.

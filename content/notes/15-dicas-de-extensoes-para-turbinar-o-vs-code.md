A página reúne extensões que o autor recomenda para deixar o VS Code mais útil no dia a dia de desenvolvimento. Os destaques incluem formatação, marcação de linhas, visualização de cores, temas, histórico de Git, ajuda com indentação, servidor local, caminhos de arquivo, colchetes coloridos, colaboração em tempo real, ícones de arquivos, WSL e ferramentas da Azure.

## Fichamento

- Beautify formata HTML, CSS, Sass, JavaScript e JSON para manter o código legível e dentro de um padrão.
- BookMarks serve para marcar linhas de código que a pessoa precisa lembrar depois.
- Color Highlight mostra as cores diretamente em arquivos CSS e Sass.
- Dracula é apresentado como um tema popular, com várias opções de cores.
- Winter is Coming é outro tema que o autor diz ter gostado pelas paletas disponíveis, e ele menciona John Papa como criador.
- Git History mostra se um código já foi comitado ou enviado por outra pessoa, quem fez a última alteração e ajuda no merge.
- GitLens ajuda a verificar quem alterou um arquivo ou uma linha no Git.
- Guides cria linhas visuais para ajudar a conferir a indentação e o fechamento de blocos como if e else.
- Live Server cria um servidor local para páginas estáticas e atualiza o navegador quando o código muda.
- Path Intellisense ajuda a encontrar rapidamente o caminho de arquivos quando o projeto tem muitas pastas.
- Rainbow Brackets colore colchetes para facilitar a conferência de fechamento.
- Live Share permite edição e depuração colaborativas em tempo real, com compartilhamento de terminais, apps locais, chamadas de voz e sessões de code review.
- VSCode-icons adiciona muitos ícones para arquivos, pastas e linguagens, facilitando a navegação visual.
- Remote - WSL permite usar o Windows Subsystem for Linux como ambiente de desenvolvimento integrado ao VS Code no Windows.
- Azure Tools traz recursos da Azure para dentro do VS Code, como Azure CLI, App Service, CosmosDB, Azure SQL Databases, Functions, Storage, Docker, Pipelines, Resource Manager e IoT Toolkit.
- O autor recomenda desinstalar extensões que não estão mais em uso, porque elas podem deixar o VS Code lento.

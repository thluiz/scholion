The author shares ten books he is currently reading and explains why he values physical books despite their cost and the time they require. The selection centers on coding interviews, algorithms, design patterns, software architecture, career development, and soft skills.

## Reading notes

- He buys books carefully because good books can be expensive and finishing one takes time.
- He likes the experience of opening the package, holding the book, and reading a physical copy.
- Cracking the Coding Interview is presented as a strong book for coding skill and interview preparation.
- Elements of Programming Interviews is described as useful for learning Python and preparing for job interviews, with 300 questions across topics like sorting, graphs, dynamic programming, and system design.
- Grokking Algorithms is noted for its illustrations and for making complex problems easier to understand.
- Problem Solving with Algorithms and Data Structure with Python is described as a solid reference for fundamentals in algorithms and data structures, with a free online version that includes an interactive code playground.
- Data Abstraction & Problem Solving with C++ is mentioned as a university book that reminds the author that concepts and principles transfer in software engineering.
- Head First Design Patterns is valued for making a challenging topic easier to learn, even if the style feels playful.
- Clean Architecture is only partly read so far, but it has already shown the author the complexity of software building.
- Career Building is described as useful for resume building, interviews, workplace culture, and burnout.
- Soft Skills, the software developer's life manual is presented as a guide to fitness, spiritual well-being, finance, self-promotion, and balancing life outside work.
- The Quick Python Book is described as a quick reference for Python learners.

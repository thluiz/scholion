The article argues that software demand is creating room for people without a traditional computer science background to learn to code. It then compares eight languages from 2016 by what they do, how hard they are to learn, and why employers wanted them.

## Reading notes

- SQL retrieves data from databases and is used to combine information into reports.
- SQL has a simple syntax and can be learned quickly, especially by people already familiar with Excel.
- Java runs on many kinds of computers, supports applications and Android apps, and is used in large systems that need scale and maintenance.
- Python is readable, easier to learn than Java or C++, and is used for web and desktop applications as well as data analysis.
- JavaScript powers interactive web effects, user interfaces, API-driven features, validation, and games.
- JavaScript is the native language of web browsers and has libraries for many tasks.
- C# is a Microsoft language used for software, Windows applications, games, and native mobile apps.
- C# is presented as friendlier for beginners than Java and supported by Visual Studio.
- C++ is used for performance-heavy work, including graphics, data handling, and device control.
- C++ is described as difficult to learn but valued for reliability and performance.
- PHP is a server-side scripting language commonly paired with SQL databases.
- PHP is used for dynamic pages, form data, cookies, database changes, and large sites like Facebook and WordPress.
- Ruby on Rails is a web framework built in Ruby for getting websites running quickly and maintainably.
- Ruby on Rails is presented as beginner-friendly and used by startups and large companies alike.

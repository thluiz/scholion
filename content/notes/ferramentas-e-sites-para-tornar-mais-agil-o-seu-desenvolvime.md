O texto lista ferramentas e sites para apoiar o trabalho em diferentes etapas do desenvolvimento web. A seleção começa no planejamento, passa por design e front-end, e termina com validação de padrões e acessibilidade.

## Fichamento

- No planejamento, o Coggle.it serve para criar sitemap e o Mural.ly ajuda em brainstorms e referências visuais.
- No design, ColorScheme e ColorSchemer.com auxiliam na escolha de paletas de cores, enquanto Grid Calculator e Grid Pak calculam grids e permitem baixar o resultado em PSD e PNG.
- No front-end, Create CSS3 gera trechos de CSS3, Css Beautifier reorganiza arquivos CSS, CSS Compressor e CSS Minifier reduzem o código, e o CSS Minifier também oferece API e outras ferramentas para JavaScript e imagens.
- Para imagens e testes, Image Optim reduz o peso de arquivos de imagem, CodePen permite testar código ao vivo, HTML5Please informa tags e propriedades de HTML5 e CSS3 que já podem ser usadas.
- Em projetos responsivos, Adaptive Images escolhe a imagem conforme a resolução do usuário e FitText ajusta o tamanho dos textos a diferentes telas.
- Na validação, o W3C Validator e o HTML Inspector conferem padrões web, o A Checker verifica acessibilidade e o Webmaster Tools do Google mostra o comportamento do robô de busca, páginas indexadas e mudanças de URL.

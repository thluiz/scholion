O autor relata sua trajetória com Visual Basic, ASP, C# e depois Ruby on Rails, dizendo que se encantou com o Ruby, mas que não conseguiu migrar totalmente para esse ecossistema. Para ele, o mercado brasileiro ainda exige que o programador mantenha a linguagem que já usa, porque há sistemas legados, pouca mão de obra qualificada e pouco investimento na linguagem.

Ele também afirma que Rails é bom para aplicações web, mas não resolve todos os cenários, como quando o cliente quer um aplicativo desktop. Por isso, recomenda não abandonar C#, Java ou outra linguagem já conhecida, seguir estudando e aproveitar alternativas como JRuby, IronRuby e projetos do .Net como o Castle.

- O texto afirma que Ruby já era a décima linguagem mais usada no mundo e poderia subir mais.
- O autor lembra que Rails é bom para desenvolvimento web, mas questiona o que fazer quando o projeto é outro, como um aplicativo desktop.

- Ele cita JRuby, IronRuby e projetos como o Castle como caminhos para quem trabalha com .Net.

The recent software sell-off is treated as evidence that SaaS is dying, but the piece argues that this reading is too broad. It says AI is still software, cloud-delivered AI is still SaaS, and the bigger shift is a new generation of software that changes which vendors gain value.

It also argues that cheaper software creation expands markets rather than shrinking them. Some hyper-narrow tools, LLM-subsumed products, and slow incumbents are exposed, but software businesses with proprietary data, regulatory lock-in, embedded workflows, and trust remain defensible. The text ends by saying that the next wave of value will come from vertical AI built on real-world coordination and data loops.

## Fichamento

- A recente queda das ações de software é apresentada como um flash crash de SaaS, mas o texto sustenta que isso não prova o fim do modelo.
- O argumento central é que IA continua sendo software, e IA entregue na nuvem continua sendo Software-as-a-Service.
- O texto diz que a mudança de paradigma traz nova terminologia e faz muita gente confundir uma nova geração de produtos com o desaparecimento do modelo de negócio.
- A tese é que IA torna o software mais acessível e mais fácil de construir, o que amplia o mercado.
- O texto separa as empresas mais expostas em três grupos: ferramentas hiperestreitas, ofertas que LLMs passam a absorver e incumbentes que demoram para adotar IA.
- Ele afirma que incumbentes lentos enfrentam o dilema de canibalizar o negócio atual e tendem a perder valor para challengers nativos de IA.
- Há também o risco de “front door”, em que agentes capturam a camada de valor incremental e empurram o sistema de registro para baixo da pilha.
- Mesmo assim, o texto diz que o crescimento do software continua forte e que a nuvem ainda tem espaço para crescer em workloads empresariais.
- O texto usa a migração de on-premise para cloud como precedente para mostrar que shifts tecnológicos podem matar algumas empresas e, ao mesmo tempo, expandir o mercado.
- Ele afirma que o software ficou mais valioso quando ficou mais barato de construir, vender e manter.
- O texto destaca que o que continua difícil não é escrever código, mas descobrir o problema, desenhar o workflow certo, distribuir o produto e conquistar confiança.
- A defesa do software passa a depender mais de expertise de domínio, distribuição, relacionamento com clientes e responsabilidade sobre o resultado.
- O texto conclui que o mercado de software cresce com IA, mas que a criação de valor vai se deslocar para startups e incumbentes capazes de construir moats de dados, workflow e confiança.

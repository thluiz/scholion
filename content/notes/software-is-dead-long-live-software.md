The recent software sell-off is treated as evidence that SaaS is dying, but the piece argues that this reading is too broad. It says AI is still software, cloud-delivered AI is still SaaS, and the bigger shift is a new generation of software that changes which vendors gain value.

It also argues that cheaper software creation expands markets rather than shrinking them. Some hyper-narrow tools, LLM-subsumed products, and slow incumbents are exposed, but software businesses with proprietary data, regulatory lock-in, embedded workflows, and trust remain defensible. The text ends by saying that the next wave of value will come from vertical AI built on real-world coordination and data loops.

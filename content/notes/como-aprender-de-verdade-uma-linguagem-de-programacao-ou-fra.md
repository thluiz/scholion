O texto reúne um processo prático para aprender uma linguagem de programação ou framework. Primeiro, pede contato inicial com boas referências, depois sugere começar com algo muito simples para colocar a mão na massa, escolher um desafio relevante, expor o código no Github, voltar aos livros com mais fluência, revisar o próprio código e encerrar o ciclo quando o objetivo de aprendizado tiver sido atingido.

## Fichamento

- Ler um pouco em fontes como livros, blogs, vídeos, artigos e revistas para ganhar familiaridade inicial com o que se quer aprender.
- Começar com um “Hello World” e preparar o ambiente para escrever algo simples e entrar em movimento.
- Escolher um desafio que seja relevante e tenha tamanho suficiente para ocupar algumas horas, mas ainda permita aprender enquanto se pratica.
- Compartilhar o código no Github e convidar outras pessoas a opinar, mesmo sem esperar muito retorno.
- Voltar aos livros depois de ganhar alguma fluência para perceber coisas que passaram despercebidas na primeira leitura.
- Revisitar o código-fonte compartilhado e aplicar as melhorias que ficaram mais claras depois do estudo.
- Definir um momento de término para o projeto de aprendizado e, depois disso, buscar um novo desafio.

The article presents JetBrains IDE plugins that support remote developers by improving collaboration, communication, time tracking, presentations, code sharing and code quality. It emphasizes that remote setups challenge developer-to-developer communication, and that these tools can make teamwork faster, more efficient and productive.

## Reading notes

- Remote development makes communication between developers harder, so the author focuses on JetBrains plugins that improve collaboration for distributed teams.
- Code With Me is described as a collaborative coding and pair programming service bundled in recent IntelliJ IDEs.
- With Code With Me you can share your JetBrains IDE by inviting others to a coding session, and guests can use a lightweight client without installing a full IDE.
- Integrated group calls and configurable permissions in Code With Me support use cases like teaching, code reviews and technical interviews.
- For remote teams, Code With Me is presented as a way to boost productivity by enabling real-time pair programming inside the IDE.
- GitLive is introduced as a plugin that makes Git activity live for team players.
- GitLive adds a tool window showing repository collaborators, their online status, and their unmerged work in progress such as branches, issues and PRs.
- GitLive allows viewing diffs of file changes, updated in real time, to keep track of what teammates are doing.
- A key GitLive feature is instant merge conflict detection, which warns early about potential conflicts.
- GitLive displays real-time gutter indicators that show where teammates have changed the file currently being edited, which is described as especially useful on larger projects.
- GitLive can start a Code With Me session with a collaborator via a click or shortcut and supports cross-IDE code sharing with VS Code users.
- For remote teams, GitLive is framed as improving communication with real-time cross-IDE collaboration, merge conflict detection and support for video calls.
- Waka Time is presented as a plugin that helps with the common remote-work problem of blurred boundaries between work and leisure.
- Waka Time adds a visual dashboard in the IDE summarizing daily coding activity, including total coding time.
- The plugin breaks down time by programming languages, IDEs and individual projects, giving more detailed insight into work patterns.
- For remote teams, WakaTime is described as a way to monitor how time is split between projects and tasks.
- The WakaTime team plan automatically detects team projects and shows how long each member has coded on each project.
- Presentation Assistant targets online code presentations where moving too fast can confuse the audience and repeated questions can disrupt the presenter.
- The plugin shows annotations of the shortcuts used while sharing the screen, helping viewers follow the live coding session.
- For remote teams, Presentation Assistant is said to be useful for company-wide presentations, screencast recording and pair programming sessions.
- GitLink is described as a simple extension focused on letting you send links with selected code from the editor to teammates for viewing in GitHub.
- Only committed changes are reflected in GitLink URLs, and the plugin is also useful for checking history, contributors or branch versions for that code.
- For remote teams, GitLink is highlighted as making it easy to send links to code snippets to coworkers.
- SonarLint is introduced as a static code analyzer that helps write efficient, safe and higher-quality code directly in the IDE.
- The article notes that modern IDEs already support static analysis, but SonarLint is positioned as taking that analysis further for detecting code smells and finding and fixing bugs.
- SonarLint integrates with most JetBrains IDEs and supports languages including C, C++, Java, JavaScript, TypeScript, Python, C#, Kotlin, Ruby, HTML and PHP.
- For remote teams, SonarLint can be used individually but is said to work best when connected to SonarQube so teams can share language rule sets and project analysis settings.
- The author concludes that good communication in distributed teams is key to productive remote work and expresses hope that these tools will make collaboration faster and more efficient.

RedMonk’s latest ranking puts Python tied with Java in second place behind JavaScript. The list is based on GitHub and Stack Overflow data, and RedMonk says Python’s rise reflects its versatility, accessibility, and growing use in new workloads.

## Reading notes

- Python now ties with Java for second place in RedMonk’s ranking of programming languages.
- The ranking is based on GitHub and Stack Overflow data and is published twice a year.
- Python’s second place is its highest position in the list so far; it had usually been fourth and rose to third three years ago.
- Stephen O’Grady attributes Python’s rise to versatility, new workloads and use cases, general accessibility, and ease of use.
- RedMonk says numerical rankings should be taken with a grain of salt.
- Python has also been rising in other popularity indexes, including Tiobe and IEEE Spectrum.
- TypeScript moved up to ninth place and is benefiting from its fit with large JavaScript codebases and from making code safer.
- Rust stayed at 21, while Go rose to 14.
- R moved up to 13, which O’Grady says is likely near its ceiling because of its specialized focus.
- Kotlin rose to 19, and Dart climbed to 24, alongside Flutter’s growth.

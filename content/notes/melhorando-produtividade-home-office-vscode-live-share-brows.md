O texto mostra que o VS Code Live Share já permitia colaboração em um mesmo editor, com edição, comentários, execução, debug e compartilhamento de terminal. A novidade é a entrada na sessão diretamente pelo navegador, sem instalação, o que amplia o uso em equipes, terceiros e salas de aula.

## Fichamento

- O Live Share permite compartilhar o editor para pair programming e group programming.
- A sessão pode incluir comentários, edição simultânea, testes, execução, debug e terminal compartilhado.
- Antes, todos precisavam ter o VS Code instalado para participar.
- A atualização permite entrar na sessão diretamente pelo browser.
- O convite continua vindo por um link gerado na sessão iniciada pelo host.
- Quem entra pelo navegador tem uma experiência completa, como se estivesse no VS Code instalado.
- A novidade já vem na extensão do Live Share, sem ação extra para quem já a usa.
- Quem ainda não tem a extensão pode baixá-la e instalá-la no editor.

## Reading notes

- The main problem is not the idea itself, but the mental walls that make starting and finishing feel harder than they are.
- The author sees starting and finishing as one of the most important meta-skills.
- The first idea can come from intuition when there is no product data yet.
- Project names can stay temporary during active development.
- Starting with a single file is presented as enough at the beginning, with structure added later.
- Tools should not become a delay; useful work can continue while installs or setup are running.

- Style tweaking is described as a major time sink, so the focus should stay on placing UI blocks and building the screen structure.
- Upgrading to the latest tools can create compatibility issues and slow progress.
- A landing page can begin from a clear reference, with the basics in place before perfection.

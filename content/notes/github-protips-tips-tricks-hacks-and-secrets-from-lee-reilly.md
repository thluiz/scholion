Lee Reilly collects small GitHub tips that make it easier to navigate repositories, manage notifications, format Markdown, and inspect repository activity. The post mixes built-in shortcuts with browser extensions and command-line tools, and it also points to a few GitHub Enterprise details.

## Reading notes

- Pressing `t` in a repository opens the fuzzy file finder, which helps jump straight to a file by typing part of its name.
- Octotree adds a tree-like file browser for navigating directories and opening files, and it works with GitHub Enterprise.
- Notifier for GitHub shows how many notifications are waiting and can also enable desktop notifications.
- Mention Highlighter makes references to a chosen name stand out inside long comment threads or dense text.
- Clicking a line number in a file creates a link to that line, and `y` or `Copy permalink` creates a canonical URL that keeps working after file changes.
- GitHub Flavored Markdown can be extended with `<kbd>` for keyboard keys, backticked hex colors for colored tiles, and `diff` code blocks for red and green line highlighting.
- `<details>` and `<summary>` keep long logs or debug output collapsed, while `<div align="center">` and `<sup>` or `<sub>` help with centering and smaller text.
- Topic URLs can be combined with `?q=` to search repositories tagged with two topics, and adding topics to repositories helps discovery.
- The unofficial GitHub Dark Theme extension works across several browsers and is presented as useful for late-night use.
- Repository activity can be read with `git shortlog -sn`, `git-quick-stats`, `git-fame`, and `git-stats`, all of which summarize commits and other contribution metrics.
- The post ends with a morse code app that generates morse code by repeatedly slamming a laptop shut, though the editor notes uncertainty about whether it is a joke.

The author describes a web-development stack shaped by backend work, but meant to cover most stages of building and launching products. He favors mature tools, fast iteration, and enough breadth to handle frontend, infrastructure, scripting, and operations.

## Reading notes

- The author works mainly in backend development and wants a broad enough skill set to build and launch products from idea to production.
- PHP and Symfony are the most familiar backend tools, with Symfony valued for OOP design, design patterns, documentation, developer experience, and performance.
- Go has become a primary language because it handles concurrency, long-running processes, command-line tools, utilities, microservices, and APIs well.
- Typescript is a future option for replacing PHP as the main OOP language, and the author is also interested in trying a more functional language.
- Vue is the preferred frontend framework because of its template-based design and ease of understanding.
- NuxtJS is used for server-side rendering, Gridsome for static sites, and Nativescript is mentioned for native mobile applications.
- Tailwind CSS is presented as a good option for styling, with Tailwind UI as a component source.
- Python is useful for scripts, but Go is increasingly the natural choice because it can run and compile into a single binary more easily.
- MySQL, Redis, ElasticSearch, Algolia, and Cloud Firestore cover relational data, cache, search, and lightweight storage for prototypes and small apps.
- Kafka is used for complex event-driven systems, while SQS and Google Cloud Pub/Sub are preferred for simpler managed messaging in personal projects.
- Google Cloud Storage, DigitalOcean Spaces, and Cloudinary are listed for object storage and media uploads.
- Netlify CMS, Prismic, Directus, and Strapi are options for content editing workflows, either Git-based, API-based, or self-hosted.
- DigitalOcean is the main hosting choice, with Google Cloud used when DigitalOcean does not cover the needed services.
- Terraform, Ansible, Netlify, Namecheap, and Cloudflare support provisioning, deployment, domains, and DNS/CDN.
- GitLab, GitHub, Codacy, VS Code, JetBrains IDEs, Docker, Docker Compose, Postman, Cacher, and DBeaver make up the author’s tooling for source control, code review, editing, containers, testing, snippets, and database access.
- The conclusion stresses keeping the stack updated, avoiding hype-driven development, and keeping mature tools in the stack so work stays sustainable.

The post announces the Elementals Multi-Pack, a weekly free brush release for SketchBook Pro users, and presents three sets focused on weather effects. It shows how the snow brushes, snowflake brushes, and elements brushes can be used to build frost, snow trails, lightning, rain, fire, and smoke effects.

It also explains how to combine brushes for more realistic results, how to use Radial Symmetry for snowflake shapes, how to change rain direction with Rotation, and how to install the .skbrushes files in the desktop app.

## Reading notes

- The Elementals Multi-Pack is made up of three brush sets.
- The Snow Brush Set includes brushes for frost, wind trails, loose swirls, floating trails, and snow pieces.
- The Snow Piece brush creates randomly sized pieces of snow when dragged around the screen.
- The Snowflake Brush Set has eight unique snowflake patterns and 16 total brushes.
- Each snowflake pattern has a matching randomized brush for wind-swept snowflake trails.
- The Radial Symmetry tool can be used to draw custom snowflakes.
- The Elements Brush Set includes lightning, rain, and fire brushes.
- Each element in the Elements Brush Set has three brushes.
- Using all three brushes of an element together is described as a way to get a more realistic effect.
- The lightning brushes can be layered to form an effective lightning bolt.
- The brushes in the Elements Brush Set are Glow style brushes.
- The rain brushes are slanted at a 45 degree angle.
- Rain direction can be changed by adjusting Rotation in Advanced Settings.
- The flame brushes can also work as smoke brushes if the color is set to white.
- The Open Flame brush is used for the body of the fire, with Flame Lick and Flame Edge added for detail.
- The Blur tool is recommended for parts of the flame to add depth and implied movement.
- In the desktop version of SketchBook 8, double-clicking a .skbrushes file installs it automatically.
- The post mentions a free trial that unlocks Pro membership for 15 days without a credit card.

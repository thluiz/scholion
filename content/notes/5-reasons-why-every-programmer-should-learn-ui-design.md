The page argues that UI design is a separate discipline, but programmers still benefit from learning its fundamentals. It says this adds a useful skill without replacing programming, helps them make more usable interfaces, and can improve how they organize their work.

## Reading notes

- UI design is presented as an independent field, but basic UI fundamentals are described as useful for programmers.
- The author says there is no wasted skill, and that learning a secondary skill can add experience without taking time away from the main skill.
- Some programmers use the claim that they are not designers to excuse poor user interfaces.
- Learning UI fundamentals is said to help programmers face fear around interface design and make usable, good-looking interfaces.
- The page says learning UI design can make a person feel more organized, because it encourages neat and visually balanced work.
- Users judge the interface, not the code, so poor UI can lead people to avoid an app even when the code is good.
- A design mistake that hurts usability or accessibility, such as poor color contrast, can make an app unusable.

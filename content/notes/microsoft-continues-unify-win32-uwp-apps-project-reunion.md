Microsoft is formalizing Project Reunion as its effort to close the divide between Win32 and UWP apps. At Build 2020, the company is previewing the first two Reunion components, WinUI 3 and WebView 2, and says both should be generally available by year-end.

The plan is to make these libraries available for developers to adopt incrementally, with GitHub used to collect requests for future components. Microsoft says this should help Windows 10 developers target the full Windows 10 PC base immediately, while the strategy appears limited to PCs rather than all Windows 10 device types.

## Reading notes

- Microsoft is continuing its plan to close the divide between Win32 and Universal Windows Platform apps.
- The effort now has a codename, Project Reunion, and a more formal structure announced at Build 2020.
- Microsoft wants developers to build Windows apps by adding modern desktop elements to Win32.
- The company is also working to decouple parts of UWP from the OS so developers can adopt them incrementally.
- The first official Reunion components are WinUI 3 and WebView 2.
- WinUI 3 is described as the modern native UI framework for Windows 10.
- WebView 2 is described as a control for integrating web content into an app.
- Microsoft is open-sourcing both libraries and letting developers pull them into code when ready.
- GitHub will be used to gather requests for the next libraries to become part of Reunion.
- Microsoft says this approach should help developers target all one billion Windows 10 PC users.
- The strategy seems limited to PCs and does not center on the broader UWP idea of targeting all Windows 10-based device types.
- Microsoft did not publicly discuss built-in Store apps for Windows 10 at Build.
- Windows Terminal 1.0 is becoming available for enterprise use.
- Microsoft is also adding WSL 2 improvements, including GPU-compute support, direct Linux GUI app support, and a simplified install command.
- Two new PowerToys utilities are being added, and Windows Package Manager Preview is getting a command-line interface.

The piece says software is beginning to write itself, with large server systems used as software robots for automated testing, staged rollouts, and other tasks done with more precision than humans. It also says developers will still exist, but their work will shift as more processing moves to servers and automation becomes necessary at scale.

## Reading notes

- Software is increasingly used to design other software, reducing the human role in some parts of development.
- Large server systems can run automated tests, check for security problems, and roll out new software in stages.
- Developers may still work in five years, even if they use virtual reality headsets instead of computer monitors.
- Devices will rely on more server power, which will make them seem smarter and more powerful.
- The scale of server management makes automation necessary because humans cannot manage it all manually.
- As long as computers need things explained to them, software engineers will still be needed.

- Current A.I. systems are presented as pieces that may be combined until they resemble strong A.I.
- The author says programmers may eventually be replaced, but that society will already have adapted to other large shifts such as self-driving cars replacing drivers.
- The article treats software development and programming robots as already large industries, especially with the internet of things.

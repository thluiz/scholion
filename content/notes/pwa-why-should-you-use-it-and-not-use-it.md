The page defines PWAs as web apps that can look and behave like regular phone apps while still working as responsive websites. It says they use JavaScript and service workers, which help with speed and load new content over time.

## Reading notes

- PWA stands for Progressive Web Apps and is presented as a web app that can be displayed like a regular app on a phone and also work like a responsive website.
- The page says a PWA is light, fast, and secure, while still using the same basic web technologies used for normal websites.
- It says service workers save the PWA server in the browser and help new feeds load, which is given as the main reason for PWA speed.
- The listed advantages are responsive layout, offline access through cached content, add-to-home-screen prompts, app-like behavior without the URL bar, push notifications, low memory use, and cross-platform support.
- The listed disadvantages are the need for a secure HTTPS connection for push notifications and prompts, a beginner-friendly setup that is not easy, no direct Play Store or App Store presence, and limited splash screen customization.

The article says Microsoft is planning further changes for the next version of Windows, likely Threshold. It presents these changes as a response to criticism of Windows 8.1 and as part of a broader effort to bring Windows 8.x, Windows Phone, and Xbox One closer together.

## Reading notes

- Threshold is described as a wave of updates that could make Microsoft’s products closer from a user-experience point of view.
- The Windows version of Threshold is said to include three SKUs: a consumer-focused Windows like today’s Windows RT, a traditional consumer x86 release, and an Enterprise SKU.
- One planned change is to let Metro apps run in floating windows on the desktop, like third-party tools already do.
- Another planned change is to make the Start menu available as an option in the next Windows version.
- The article says these changes are still being verified, but treats them as a meaningful sign that Microsoft is responding to complaints.
- It links the Threshold news with the idea of a more consolidated OS across devices.

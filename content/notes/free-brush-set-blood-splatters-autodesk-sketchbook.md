SketchBook offers a free Blood Splatter Brush Set for SketchBook Pro members. The set is timed for Halloween and is meant to add murder, mayhem, and horror effects to drawings.

It includes bloody handprints, drips, slashes, droplets, and chunks, with brush names like Desperate Smear, Sad Puddle, and “Oh, God It’s All Over.” The post says the brushes can also work as subtle background effects and can be combined with the Skullz Brush Set. For SketchBook desktop version 8, the .skbrushes file installs by double-clicking.

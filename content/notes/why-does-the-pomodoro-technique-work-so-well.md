The post argues that Pomodoro works well because it uses a time-sensitive trigger. By scheduling a focus event, it aligns a basic mental control structure with task focus and pushes other concerns out of working memory.

## Reading notes

- The author compares Pomodoro to a deferred memory or trigger, where an action follows a condition.
- He says this structure is like an if statement, but time sensitive in the brain.
- Pomodoro works because it aligns that primitive structure with task focus.
- Scheduled events can cloud working memory and make focus harder.
- Pomodoro uses the same phenomenon in reverse by deliberately scheduling a focus event.
- That focus event pushes other concerns out of working memory and clears space for later use.
- The post treats this as an example of a simple technique producing a high-level effect.

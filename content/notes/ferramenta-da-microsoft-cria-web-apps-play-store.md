A Microsoft atualizou o PWABuilder para suportar o Bubblewrap, uma ferramenta de linha de comando que permite criar projetos TWA sem precisar instalar o Android Studio SDK. A atualização mantém o foco em converter apps web em apps para Android com menos etapas de configuração.

## Fichamento

- O PWABuilder agora suporta Bubblewrap.
- O Bubblewrap só precisa do node.js instalado para criar projetos TWA.
- Com isso, deixa de ser necessário instalar o Android Studio SDK nesse fluxo.
- A TWA permite que apps web sejam executados em janelas do Chrome como apps para Android.
- Entre as funções trazidas pela TWA estão notificações push e acesso offline.
- O PWABuilder também permite personalização fácil da aplicação, como barras de status e navegação do Android, tela inicial, comportamento de retorno e algumas configurações automáticas.

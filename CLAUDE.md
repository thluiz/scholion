# Scholion — Instruções do projeto

## Search-first interativo

Antes de draftar qualquer nota ou pesquisa nova, buscar no vault
(`content/notes/` + `content/research/`) por temas, autores, ideogramas
e termos relacionados. Mostrar os matches encontrados com contexto
breve (1 linha por nota: título + slug + 1 frase do conteúdo) e
**esperar o autor apontar** quais linkar, expandir, ou ignorar antes
de redigir qualquer parágrafo.

Não draftar primeiro e linkar depois. A ordem é: buscar → listar →
esperar → draftar.

Se a busca não retornar nada relevante, dizer isso explicitamente
("nenhuma nota relacionada encontrada") antes de seguir para o draft.

## Source-or-silence

Toda afirmação factual em uma nota (etimologia, datação, glosa,
autoria, citação, atribuição) precisa de **citação de fonte inline**.
Se não houver fonte atestada: **omitir a afirmação da nota** e
**avisar o autor no chat** que ficou de fora por falta de fonte.
Nunca parafrasear de forma plausível para preencher.

Nunca escrever na nota que a fonte não foi encontrada ("não foi
possível confirmar", "não há registro"). Isso é narração de processo,
violação irmã do source-or-silence: o aviso é para o autor, não para
o leitor. Em docs de pesquisa, item provisório leva ⚠ (convenção da
skill `research`); esse é o único lugar onde "ainda não verificado"
aparece no texto.
